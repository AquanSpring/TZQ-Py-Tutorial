# 变量与数据类型

## 为什么需要变量？

到目前为止，我们的代码都是“执行完就忘”：`print` 输出一句话，程序结束，什么也没留下。而真实的程序需要**记住**数据——你的游戏等级、购物车里的商品、银行账户的余额。

**变量（Variable）** 就是程序用来“记住”数据的工具。这一章我们学习两件事：怎么用变量记住数据，以及数据本身有哪些“种类”（数据类型）。

## 什么是变量

可以把变量理解成**贴在数据上的标签**：数据本身放在内存里，变量名就是指向它的标签，你通过标签随时找到这份数据。

给变量赋值的写法是：`变量名 = 数据`，中间的 `=` 叫**赋值号**：

```python
name = "小明"    # 把字符串 "小明" 贴上 name 这个标签
age = 18         # 把整数 18 贴上 age 这个标签

print(name)      # 小明
print(age)       # 18
```

> **注意**：`=` 不是数学里的“相等”，而是“把右边的值赋给左边”。读作“把 18 赋给 age”，而不是“age 等于 18”。

变量最大的特点是“变”——它的值可以随时更新：

```python
score = 60
score = score + 40    # 先算右边的 60 + 40，再把结果 100 赋回 score
print(score)          # 100
```

第二行是理解赋值的关键：**Python 总是先算等号右边，再把结果赋给左边**。如果 `=` 真的是“相等”，这行代码在数学上根本不成立——这正是它不是等号的证明。

## 给变量起名字

变量名不是随便起的，它有两套约束。

**硬性规则**（违反会直接报错）：

1. 只能由**字母、数字、下划线**组成，如 `name`、`age2`、`student_score`；
2. 不能以**数字**开头（`2name` ❌，`name2` ✅）；
3. 不能使用 Python 的**关键字**（`if`、`for`、`while`、`class` 等 30 多个被语言本身占用的词）；
4. **严格区分大小写**——`Age` 和 `age` 是两个不同的变量（还记得第四章的规则四吗？）。

**软性讲究**（不违反会更好）：

- **见名知意**：存学生年龄就叫 `student_age`，别叫 `a`、`x1`；
- 多个单词用**下划线连接**：`user_name`、`total_price`，这是 Python 官方推荐的风格；
- 建议用英文单词，避免拼音缩写带来的歧义。

还有一条常见约定：**不该被修改的量**用全大写命名，如 `PI = 3.14159`、`MAX_RETRY = 3`。Python 并没有真正的“常量”，全大写只是提醒读代码的人：请别改它。

**动手试一试**：故意输入 `2name = 1` 并运行，观察报错信息。学会读懂 `SyntaxError`，是你排查代码问题的第一课。

## 常用的数据类型

数据是有“种类”的，Python 会自动识别最常见的四种：

| 类型 | 名称 | 例子 | 一句话说明 |
| --- | --- | --- | --- |
| `int` | 整数 | `18`、`-5`、`0` | 不带小数点的数 |
| `float` | 浮点数 | `3.14`、`-0.5` | 带小数点的数 |
| `str` | 字符串 | `"hello"`、`"你好"` | 引号包住的一串字符 |
| `bool` | 布尔 | `True`、`False` | 只有两个值，表示“真/假” |

用内置的 `type()` 函数可以查看任何数据的类型：

```python
print(type(18))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type("hello"))    # <class 'str'>
print(type(True))       # <class 'bool'>
```

两个值得注意的细节：

- 布尔值的 `True` 和 `False` **首字母必须大写**——又一次呼应第四章：Python 严格区分大小写。
- 引号决定一切：`18` 是整数，`"18"` 是**字符串**。长得一样，类型完全不同，这也正是下面类型转换存在的原因。

> **说明**：这四种是起步阶段最常用的类型。后面章节还会遇到列表、字典等能装下更多数据的“容器型”类型，现在先把这四种用熟。

## 类型转换：在类型之间搭桥

不同类型的值不能随意混用。比如把字符串和整数直接相加，程序会报错：

```python
print("5" + 5)    # ❌ TypeError：字符串只能和字符串拼接，不能拼接整数
```

解决的办法是**类型转换**，Python 提供了三个最常用的转换函数：

```python
int("5")       # 字符串 → 整数，得到 5
float("3.14")  # 字符串 → 浮点数，得到 3.14
str(100)       # 整数 → 字符串，得到 "100"
```

一个最实用的场景——先把字符串转成数字，再做数学运算：

```python
age = "18"          # 此时 age 是字符串
age = int(age)      # 转换成整数
print(age + 1)      # 19 ✅
```

反过来，想把数字拼进一句话里，就要先用 `str()` 把数字转成字符串：

```python
age = 18
print("我今年 " + str(age) + " 岁")    # 我今年 18 岁
```

> **常见问题**：`"5" + 5` 报错？先看错误类型 `TypeError`（类型错误），再读提示信息——它会告诉你哪两种类型出了问题。看懂报错，比背答案更重要。

## 本章挑战作业

这一章的工具是：赋值、四种类型、`type()`、类型转换。下面的题只用这些，**没有参考答案**——先自己挣扎 30 分钟，卡住就把问题拆小。

**任务一：交换两个变量**。程序开头是：

```python
a = 1
b = 2
```

请通过若干条赋值语句，让程序结束时 `a` 是 2、`b` 是 1，最后用两个 `print` 验证。约束：不许直接写 `a = 2` 和 `b = 1`——你的代码要**换了两个别的数也能正确交换**。

**任务二：用 `type()` 证明引号的力量**。对 `"5"`、`5.0`、`5` 分别用 `type()` 查看并打印，在每行后面用注释记下结果，并用一句话回答：它们为什么是三种不同的类型？

> **提示（任务一）**：直接 `a = b` 会把 2 复制过去，1 就“丢了”。想想：怎么在覆盖之前，把旧值**暂存**在一个新变量里？这是几乎所有编程语言教学里的经典第一题，值得亲手推一遍。

**自测标准**：任务一换任意两个初始值（比如 `a = "x"`、`b = "y"`）依然交换成功；任务二的三个 `type()` 结果你都解释得上来。

## 本章小结

- 变量是贴在数据上的标签，`=` 是赋值号：**先算右边，再赋给左边**。
- 命名有硬规则（字母/数字/下划线、不数字开头、区分大小写、避开关键字）和软讲究（见名知意、下划线连接）。
- 基础数据类型四种：`int`、`float`、`str`、`bool`，用 `type()` 查看类型。
- `18` 和 `"18"` 类型不同；`int()`、`float()`、`str()` 负责在类型之间转换。
