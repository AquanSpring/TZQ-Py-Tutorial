# Python 简介

## 认识 Python：优雅、强大的现代编程语言

**Python** 是一门高层次的通用编程语言，由荷兰程序员吉多·范罗苏姆（Guido van Rossum）于 1989 年圣诞节期间开始编写，并于 1991 年正式发布第一个版本。它的核心设计理念是“优雅、明确、简单”，语法非常贴近自然英语，代码具有极高的可读性。此外，Python 开源、免费，可以在 Windows、macOS、Linux 等主流操作系统上运行。

> **小趣闻**：Python 这个名字并不是来自蟒蛇，而是取自 Guido 钟爱的英国喜剧团体 **Monty Python**（蒙提·派森）。他希望这门语言能像这部喜剧一样，让编程变得有趣。

## 为什么选择 Python？

- **极简易读**：使用缩进来定义代码块，省去了复杂的括号与分号，学习曲线平缓，是公认最适合初学者入门的编程语言之一。
- **功能全面**：拥有“开箱即用”的标准库，以及数以万计的第三方库（如 NumPy、Pandas、PyTorch、Django），能极大提高开发效率。
- **应用极其广泛**：
  - **人工智能与数据科学**：机器学习、深度学习、数据挖掘与可视化的首选语言之一。
  - **网络爬虫与自动化办公**：快速抓取网页数据，批量处理 Excel、PDF 与日常重复任务。
  - **后端与网络开发**：驱动 Instagram、Reddit 等大型服务的后端系统。
  - **运维自动化与脚本编写**：跨平台运行，快速搞定系统管理任务。

## 你的第一行代码

在 Python 中，打印经典的欢迎语句只需要一行：

```python
print("Hello, World!")
```

这行代码的含义是：调用 Python 内置的 `print()` 函数，把括号中的内容输出到屏幕上。现在你还不能运行它，但已经能直观感受到 Python 语法的简洁——**没有分号，没有大括号，读起来就像一句英语**。

> **说明**：本教程基于 **Python 3.x**（当前的主流版本）。早期的 Python 2 已于 2020 年停止维护，查阅资料时请注意区分版本。
