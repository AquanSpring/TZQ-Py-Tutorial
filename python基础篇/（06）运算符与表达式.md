# 运算符与表达式

## 让程序开始“算”

上一章我们让程序“记住”了数据，这一章让它“干活”——**运算**。这本来就是计算机最擅长的事。

先认识两个词：**运算符（Operator）**是 `+`、`-`、`*` 这些运算符号；把数据和运算符组合起来、能算出一个结果的式子叫**表达式（Expression）**。表达式算出的结果可以存进变量：

```python
price = 5
count = 3
total = price * count    # 右边是一个表达式，算出 15 赋给 total
print(total)             # 15
```

## 算术运算符

Python 提供了 7 个算术运算符，前三个和数学完全一样，后四个是编程特有的：

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `+` | 加 | `7 + 2` | `9` |
| `-` | 减 | `7 - 2` | `5` |
| `*` | 乘 | `7 * 2` | `14` |
| `/` | 除 | `7 / 2` | `3.5` |
| `//` | 整除（只留整数部分） | `7 // 2` | `3` |
| `%` | 取余 | `7 % 2` | `1` |
| `**` | 幂（乘方） | `7 ** 2` | `49` |

三个要点：

- **`/` 的结果永远是浮点数**：`10 / 2` 得到的是 `5.0`，不是 `5`——呼应上一章的类型知识。
- **`%` 取余非常实用**：判断奇偶（`n % 2` 结果是 0 就是偶数）、提取个位（`123 % 10` 得到 3）都靠它。
- **`//` 是“向下取整”的整除**：正数时就是“扔掉小数部分”，但负数时会往更小的方向取，如 `-7 // 2` 是 `-4`。初学阶段记住正数用法即可，见到负数结果时想起这条。

**动手试一试**：在 VS Code 里把这个表格逐行敲一遍——先口算，再运行验证。全对说明你已经掌握了。

## 运算优先级

表达式里有多个运算符时，运算顺序和数学一致：

1. **括号**最优先；
2. 其次是**幂**（`**`）；
3. 再是**乘、除、整除、取余**；
4. 最后是**加、减**；同级运算从左到右。

```python
print(2 + 3 * 4)     # 14，先乘后加
print((2 + 3) * 4)   # 20，括号改变顺序
```

> **建议**：不确定顺序时，**加括号**。括号既不会算错，还能让读代码的人一眼看懂你的意图。

### 还有一类：位运算（认识即可）

除了上面这些，Python 还有一组**位运算符**——它们直接操作数字的二进制位：

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `&` | 按位与 | `6 & 3` | `2` |
| `\|` | 按位或 | `6 \| 3` | `7` |
| `^` | 按位异或 | `6 ^ 3` | `5` |
| `~` | 按位取反 | `~6` | `-7` |
| `<<` | 左移 | `1 << 3` | `8` |
| `>>` | 右移 | `8 >> 2` | `2` |

```python
print(6 & 3, 6 | 3, 6 ^ 3, ~6, 1 << 3, 8 >> 2)    # 2 7 5 -7 8 2
```

初学阶段**不用背**，认识它们、知道“这是位运算”就够了。真正用得上它们的场合通常是读写硬件、压缩数据、做权限开关——遇到时再回来查这张表。

### 一行写不下怎么办

表达式太长时，有两种续行办法。**首选括号**：把内容包进 `()`、`[]`、`{}` 里，Python 就知道还没写完，可以随便换行：

```python
total = (1 + 2
         + 3 + 4)
print(total)      # 10

names = [
    "小明",
    "小红",
]
print(names)      # ['小明', '小红']
```

括号不够用时（很少见），才在行尾用反斜杠 `\` 强行续行：

```python
total = 1 + 2 + \
        3 + 4
print(total)      # 10
```

**实际写代码优先用括号**——反斜杠容易被漏掉或误删，括号版本也更好看。

## 字符串也能“运算”

`+` 和 `*` 对字符串同样有效，但含义变了：

```python
first = "Hello, "
second = "World!"
print(first + second)    # Hello, World!  —— + 是拼接

print("-" * 20)          # -------------------- —— * 是重复
print("Ha" * 3)          # HaHaHa
```

注意：`+` 的两边必须是**同是字符串**——第五章 `"5" + 5` 报的 `TypeError` 就是这个原因，需要先转换类型再运算。

## 比较运算符：结果是“真 / 假”

比较运算符用来比较两个值的关系，**运算结果是一个布尔值**——上一章学的 `bool` 类型，在这里正式派上用场：

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `==` | 等于 | `7 == 7` | `True` |
| `!=` | 不等于 | `7 != 7` | `False` |
| `>` | 大于 | `7 > 2` | `True` |
| `<` | 小于 | `7 < 2` | `False` |
| `>=` | 大于等于 | `7 >= 7` | `True` |
| `<=` | 小于等于 | `7 <= 2` | `False` |

```python
age = 18
print(age >= 18)    # True
print(age == 20)    # False
```

> **本章最重要的区别**：`=` 是赋值（把值存进变量），`==` 是比较（问两者是否相等）。写成 `if x = 5` 之类的错误，大多源于把这两个弄混了。

Python 还支持数学里的**连写比较**：`18 <= age <= 60` 等价于 `age >= 18 and age <= 60`（`and` 下一章细讲），判断“区间”时非常好用。

顺带一提，字符串也能比较大小（按字符编码顺序），这个规则用到时再细讲，现在先不深究。

## 简写运算符：+= 家族

“在原值基础上更新”是高频操作，Python 提供了简写形式：

```python
count = 0
count += 1    # 等价于 count = count + 1，count 变成 1
count += 1    # count 变成 2
print(count)  # 2
```

`-=`、`*=`、`/=`、`//=` 都是同样的道理。其中 `+=` 出现频率最高，务必熟练。

## 一个著名的坑：浮点数误差

运行下面这行代码，结果可能出乎你的意料：

```python
print(0.1 + 0.2)    # 0.30000000000000004 ？
```

这不是 bug，也不是你写错了——计算机内部用**二进制**存储小数，而很多十进制小数（比如 0.1）无法被二进制精确表示，于是产生微小的误差。所有编程语言都有这个现象。

初学阶段的应对：用 `round()` 把结果保留到指定位数，如 `round(0.1 + 0.2, 2)` 得到 `0.3`。

> **注意**：`round()` 并不是严格的“四舍五入”，它用的是“四舍六入五成双”——`round(2.5)` 得到的是 `2`，不是 `3`；`round(3.5)` 才得到 `4`。所以它适合用来收拾显示上的小尾巴，**不适合做精确计算**。以后涉及金额等场景，我们再介绍专门的 `Decimal` 模块。

## 本章挑战作业

一道流传千年的算术题，只用变量和运算符（**不许用 if**——下一章才学），**没有参考答案**：

**鸡兔同笼**。笼中有 35 个头、94 只脚。设鸡有 `chickens` 只、兔有 `rabbits` 只，用表达式算出它们各是多少只，并 `print` 出结果。

要求：

1. 先把解题思路写在注释里（用中文描述你的算式逻辑），再翻译成代码；
2. 结果必须由表达式**算出来**，不许直接写 `chickens = 23`；
3. 用 `print` 输出两行验证：头数之和是否为 35，脚数之和是否为 94（提示：比较表达式会输出 True/False，回忆本章的比较运算符）。

> **提示**：假设 35 只全部是鸡，脚只有 70 只，比实际的 94 少了 24 只。每把一只鸡换成兔，脚就多 2 只——24 里有几个 2，就有几只兔。把这个思路用 `-`、`*`、`//` 翻译成表达式。

**自测标准**：输出鸡 23 只、兔 12 只，且两行验证都是 `True`。

## 本章小结

- 表达式 = 数据 + 运算符，总能算出一个结果；结果常被赋给变量。
- 七个算术运算符：`+ - * / // % **`；`/` 的结果永远是浮点数。
- 优先级：括号 > 幂 > 乘除 > 加减，不确定就加括号。
- 字符串支持 `+`（拼接）和 `*`（重复），但 `+` 两边必须都是字符串。
- 比较运算符的结果是布尔值；`==` 是比较，`=` 是赋值。
- `+=` 等简写运算符让“在原值上更新”更简洁。
- 浮点误差源于二进制存储，属正常现象，可用 `round()` 缓解。
