# 面向对象编程入门

## 从“散装数据”到“对象”

描述一只狗，你需要几个变量：名字、年龄；再写几个函数：叫、吃。一只狗还好，一百只呢？变量满天飞，数据和操作互不关联。

**面向对象编程（OOP）**的思路：把“数据”和“操作这些数据的函数”打包成一个整体——**对象（Object）**。狗的名字、年龄和“叫”这个行为，都属于这只狗。

**类（Class）**是对象的“图纸”：先定义图纸，再按图纸造出一个个对象（也叫**实例**）。

## 定义一个类

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(self.name + "：汪汪！")

my_dog = Dog("旺财", 3)      # 按图纸造一只狗
print(my_dog.name)           # 旺财
my_dog.bark()                # 旺财：汪汪！
```

这段代码信息量大，逐条解剖：

- `class Dog:` 定义类，类名按惯例**首字母大写**（多个单词连写，如 `MyDog`，称为大驼峰）；
- `__init__` 是特殊方法：每次造新对象时**自动执行**，负责初始化。`Dog("旺财", 3)` 里的两个实参传给它；
- `self` 指“当前这个对象自己”。执行 `my_dog.bark()` 时，`self` 就是 `my_dog`；
- `self.name = name` 把传入的值挂在这个对象身上，成为它的**属性**；
- `bark` 是**方法**——写在类里面的函数。第十章的 `scores.append()` 正是列表对象的方法，现在你知道它的由来了。

## 为什么要这么麻烦

用散装变量描述三只狗：`name1`、`name2`、`name3`……每只狗的数据和操作互不关联，改一处容易漏一片。用类，数据和操作绑定在一起，多少只都不乱：

```python
dogs = [Dog("旺财", 3), Dog("小黑", 2), Dog("豆豆", 5)]

for dog in dogs:
    dog.bark()
```

输出：

```text
旺财：汪汪！
小黑：汪汪！
豆豆：汪汪！
```

## 继承：站在类的肩膀上

类可以继承另一个类的全部能力，只需补充自己特有的部分：

```python
class Puppy(Dog):          # 幼犬“是一种”狗 —— 继承 Dog
    def roll(self):
        print(self.name + " 打了个滚")

p = Puppy("团子", 1)
p.bark()        # 团子：汪汪！ —— 从 Dog 继承来的
p.roll()        # 团子 打了个滚 —— 自己新增的
```

“幼犬是一种狗”——继承表达的就是这种 **is-a**（是一种）关系。

> **说明**：OOP 是个大话题，本章只求达到两个目标：看得懂别人写的类、自己会定义简单的类。封装、多态等深入内容，进阶时再学。

### 子类想改掉父类的初始化？用 `super()`

上面的 `Puppy` 没有自己的 `__init__`，所以直接用了父类的。如果幼犬要多一个属性（比如“断奶了没”），就得自己写 `__init__`——同时**别丢掉父类已经做好的那部分工作**，这时用 `super()`：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(self.name + "：汪汪！")


class Puppy(Dog):
    def __init__(self, name, age, weaned):
        super().__init__(name, age)     # 先让父类把 name、age 安排好
        self.weaned = weaned            # 再补自己特有的属性

    def bark(self):
        super().bark()                  # 也能调用父类的同名方法
        print("（奶声奶气）")


p = Puppy("团子", 1, False)
print(p.name, p.age, p.weaned)     # 团子 1 False
p.bark()
```

`super()` 的意思是“我的父类”。写了它，将来父类的初始化逻辑改了，你不用跟着改一遍——这才是继承真正省事的地方。

## 动手：写一个 Student 类

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def introduce(self):
        print(f"我叫 {self.name}，考了 {self.score} 分")

    def is_passed(self):
        return self.score >= 60

stu = Student("小明", 85)
stu.introduce()               # 我叫 小明，考了 85 分
print(stu.is_passed())        # True
```

`is_passed` 返回布尔值（第十三章的 `is_` 前缀惯例），`introduce` 用了 f-string（第九章）——一个小小的类，浓缩了大半本教程。

## 本章挑战作业

**银行账户类**。把本章的知识组合成一个真正有用的类，**没有参考答案**：

写一个 `BankAccount` 类：

1. 属性：`owner`（户主姓名）、`balance`（余额，**新建账户时必须为 0**）；
2. 方法 `deposit(amount)`：存钱，余额增加；
3. 方法 `withdraw(amount)`：取钱——余额够就扣减并输出新余额；**余额不足时输出提示，并且余额一分不变**；
4. 方法 `show()`：输出“户主：xxx，余额：xxx 元”。

验证流程（写在你自己的代码里）：

```python
acc = BankAccount("小明")
acc.deposit(100)
acc.withdraw(30)
acc.withdraw(500)     # 应该被拒绝
acc.show()            # 户主：小明，余额：70 元
```

要求：

- 余额不足的判断用 `if / else`（第七章），条件是 `amount > self.balance`（比较运算符是第六章的）；
- 新建账户时调用方只传姓名：`BankAccount("小明")`——想想 `__init__` 的参数怎么设计；
- 三次操作后余额必须恰好是 70，分毫不能差。

> **提示**：对照 Dog 类的结构：`__init__` 里两个属性，一个由实参传入、一个固定为 0。`withdraw` 里的“拒绝”不是 return False 那种复杂操作——打印一句提示、什么都不改，就是拒绝。

**自测标准**：四次调用后输出余额 70；把 `withdraw(500)` 换成 `withdraw(70)` 再跑一遍，余额应为 0，且继续取钱会被拒绝。

## 本章小结

- 类是图纸，对象（实例）是按图纸造的产品；数据和函数打包在一起。
- `__init__` 负责初始化，`self` 指对象自己，属性挂在 `self` 上，方法写在类里。
- 类名用大驼峰；`.` 用来访问对象的属性和方法。
- 继承用 `class 子类(父类)` 表达“是一种”的关系，子类自动拥有父类的能力。
