# 列表与元组

## 一个变量装下所有成绩

要存全班 50 个学生的成绩，起 50 个变量名？当然不。**列表（List）**是 Python 最常用的容器——用方括号把一组数据装进一个变量：

```python
scores = [90, 85, 77, 100, 66]
print(scores)        # [90, 85, 77, 100, 66]
```

列表里的元素可以是任何类型，甚至混合存放，但同一类数据放一起更常见。

## 用索引访问：从 0 开始数

```python
scores = [90, 85, 77, 100, 66]

print(scores[0])     # 90 —— 第一个元素
print(scores[3])     # 100
print(scores[-1])    # 66 —— 负数表示倒数
```

**索引从 0 开始**是编程世界的通用约定，也是新手第一大坑：“第 1 个”是 `[0]`，“第 5 个”是 `[4]`。

索引越界会报错——只有 5 个元素，访问 `scores[5]` 就得到 `IndexError`。

## 遍历：配合 for 逐个处理

第八章说过 `for` 的本质是遍历序列，列表就是最典型的序列：

```python
for s in scores:
    print(s)
```

需要序号时，最地道的工具是 **enumerate()**——它每轮交出一个 `(序号, 元素)`，用两个变量接住（这种写法叫解包，本章元组一节会讲）：

```python
for i, s in enumerate(scores):
    print(f"第 {i + 1} 个成绩是 {s}")
```

两个列表一一对应地并行遍历，用 **zip()**：

```python
names = ["小明", "小红"]
scores2 = [90, 85]

for name, score in zip(names, scores2):
    print(f"{name}：{score} 分")
```

## 增、删、改

```python
scores = [90, 85, 77]

scores.append(100)      # 末尾添加 → [90, 85, 77, 100]
scores.insert(0, 60)    # 插到索引 0 的位置 → [60, 90, 85, 77, 100]
scores[1] = 86          # 修改 → [60, 86, 85, 77, 100]
scores.remove(77)       # 按值删除 → [60, 86, 85, 100]
last = scores.pop()     # 取出并返回最后一个元素 → scores 变 [60, 86, 85]，last 是 100
```

三个“加”各管一处：`append()` 加在末尾、`insert()` 加在指定位置、`extend()` 把另一个列表整个接上。

两个“删”要分清：`remove()` 按**值**删，而且**只删第一个匹配项**（列表里有两个 77，也只删掉前面那个）；`pop()` 按**位置**删，并把删掉的值交给你——要“用完就删”时非常顺手。

列表也支持 `+` 和 `*`（规则和字符串一样）：

```python
a = [1, 2, 3]
b = [4, 5]

print(a + b)      # [1, 2, 3, 4, 5] —— 拼接
a.extend(b)       # 把 b 的元素逐个塞进 a，效果类似 a = a + b；但 extend 是原地修改，不产生新列表
```

> **细节**：`scores.append(100)` 这种用“点”调用的写法叫**方法（Method）**——挂在数据身上的函数。第十三章正式学函数，第十七章你会发现方法正是面向对象的冰山一角。

## 切片：取一段

```python
scores = [90, 85, 77, 100, 66]

print(scores[1:3])    # [85, 77] —— 索引 1 到 2，不含 3
print(scores[:2])     # [90, 85] —— 从头开始取
print(scores[2:])     # [77, 100, 66] —— 一直取到结尾
```

规则和 `range` 一致：**含头不含尾**。切片还有第三个参数**步长**：`scores[::2]` 每两个取一个，得到 `[90, 77, 66]`；步长为 -1 时，`scores[::-1]` 就是整个列表倒过来。

> **重要细节：赋值不是复制**。`b = scores` 并不会复制列表，只是给**同一个列表**多贴了一个标签——通过 `b` 做的修改，`scores` 看得一清二楚。想要真正独立的副本，用切片：`b = scores[:]`。这是新手最容易踩的隐性坑，本章挑战作业会用到它。

## 常用统计与成员判断

```python
scores = [90, 85, 77, 100, 66]

print(len(scores))    # 5    个数
print(sum(scores))    # 418  总和
print(max(scores))    # 100  最大
print(min(scores))    # 66   最小
print(sum(scores) / len(scores))    # 83.6 平均分
```

`in` 可以判断元素是否存在，结果是布尔值——第五章学的 `bool` 又立新功：

```python
print(100 in scores)    # True
print(59 in scores)     # False
```

## 排序：sort 与 sorted

```python
scores = [90, 85, 77, 100, 66]

scores.sort()                  # 原地排序，直接改自己 → [66, 77, 85, 90, 100]
scores.sort(reverse=True)      # 倒序 → [100, 90, 85, 77, 66]

new_list = sorted(scores)      # 不动原列表，返回一个排好的新列表
```

记住这对搭档的区别：**`sort()` 改自己，`sorted()` 给新列表**——想保留原始顺序时用后者。另有一个 `reverse()` 方法，不做比较排序，只把现有顺序整个颠倒。

### 选学：按“规则”排序

`sort()` 和 `sorted()` 默认按大小排。想按**自己的规则**排时，用 `key=` 告诉它“拿什么去比较”：

```python
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=len))     # ['kiwi', 'apple', 'banana'] —— 按长度排

nums = [-5, 3, -1, 4]
print(sorted(nums, key=abs))      # [-1, 3, 4, -5] —— 按绝对值排

pairs = [(2, "b"), (1, "c"), (3, "a")]
print(sorted(pairs, key=lambda p: p[1]))   # [(3, 'a'), (2, 'b'), (1, 'c')] —— 按第二个元素排
```

`lambda p: p[1]` 是“临时用一次的小函数”，等价于一个只做 `return p[1]` 的函数。现在只要**看得懂**，用到时会照抄 `key=lambda ...` 这个形状就够了。

## 元组：不可修改的列表

**元组（Tuple）**用圆括号，用法和列表几乎一样，唯一区别：**创建后不能增、删、改**：

```python
point = (3, 5)

print(point[0])       # 3 —— 访问没问题
point[0] = 10         # ❌ TypeError！元组不可修改
```

什么时候用元组？**数据不该被改动**的时候——坐标、一年的十二个月、固定的配置项。

再学一个实用语法——**解包**：一次把元组里的值分别赋给多个变量：

```python
x, y = (3, 5)
print(x, y)           # 3 5
```

## 列表 vs 元组

| | 列表 list | 元组 tuple |
| --- | --- | --- |
| 符号 | `[ ]` | `( )` |
| 可否修改 | 可以 | 不可以 |
| 典型用途 | 一组会变化的数据 | 一组固定不变的数据 |

## 本章挑战作业

**体操评分**。真实比赛里，选手的得分要**去掉一个最高分、去掉一个最低分**后取平均，**没有参考答案**：

```python
scores = [9.2, 8.8, 9.5, 8.9, 9.1, 8.7]    # 六位裁判的打分，互不相同
```

请算出最终得分并输出，保留两位小数。

要求：

1. 最高分和最低分必须用 `max()` / `min()` 找出来，不许用眼睛看后写死 `9.5` 和 `8.7`；
2. 原列表 `scores` 在程序结束后必须保持原样——直接在它上面 `remove` 会把它改掉，想想本章有没有办法先得到一个**副本**再删；
3. `sum / len` 求平均，f-string 格式化输出。

> **提示**：本章的切片可以复制列表——`scores[:]` 就是“从头到尾整段取”出来的副本。在副本上 `remove(max(...))` 和 `remove(min(...))`，再对副本求平均。如果结果出现 `9.000000000000002` 这种尾巴——回忆第六章的浮点误差，用 `:.2f` 解决。

**自测标准**：去掉 9.5 和 8.7 后，剩余四个数之和为 36.0，最终输出 `9.00`。

## 本章小结

- 列表用 `[]` 装一组数据，索引从 0 开始，负索引从后往前数。
- `for` 遍历列表；要序号用 `enumerate()`，两个列表并行遍历用 `zip()`。
- `append` 添加、`insert` 插到指定位置、`remove` 按值删（只删第一个）、`pop` 按位置删、赋值修改、`+ / extend` 拼接；“点”出来的用法叫方法。
- 切片含头不含尾，步长可控制方向；`b = a` 只是别名，真副本要用 `a[:]`。
- 排序：`sort()` 改自己，`sorted()` 返回新列表；`len / sum / max / min / in` 是高频工具。
- 元组是不可修改的列表，适合固定不变的数据；解包可以一次赋多个变量。
