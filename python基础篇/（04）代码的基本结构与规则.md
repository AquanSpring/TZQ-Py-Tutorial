# 代码的基本结构与规则

## 开始之前

上一章的“动手环节”里，你已经装好了 VS Code 并配置好 Python 解释器。从这一章起，我们正式开始写代码。

写代码就像学一门新语言，先要掌握它的基本“游戏规则”。本章的四条规则会贯穿你整个编程生涯，请务必亲手把每个例子敲一遍——**编程是练出来的，不是看出来的**。

## 规则一：代码自上而下，逐行执行

程序默认从第一行开始，一行接一行地往下执行：上一行执行完毕，才会执行下一行。这建立了程序的**时序概念**——代码的书写顺序，就是它的执行顺序。

在 VS Code 中新建文件 `demo.py`，输入以下代码并运行：

```python
print("我先执行")
print("我后执行")
print("我最后执行")
```

运行结果：

```text
我先执行
我后执行
我最后执行
```

输出的顺序和代码的书写顺序完全一致。试着把三行代码调换位置再运行一次，观察输出顺序的变化，你会更直观地感受到“逐行执行”。

> **提前说明**：以后学到条件语句和循环，你会发现代码也可以“跳着执行”或“重复执行”，但“从上到下”始终是最基本的默认规则。

## 规则二：缩进（Indentation）即语法

大多数语言用花括号 `{}` 来划分代码块，Python 不一样——**它用缩进来表示代码的层次和归属**。缩进相同的连续语句，属于同一个代码块。

先看一个例子（`if` 语句现在不用完全理解，后面章节会详细讲，这里只感受缩进的作用）：

```python
age = 18

if age >= 18:
    print("你已成年")      # 缩进了 4 格：属于 if，条件成立才执行
    print("欢迎注册")      # 缩进了 4 格：属于 if，条件成立才执行

print("我不受 if 控制")     # 没有缩进：不属于 if，总会执行
```

前两个 `print` 前面有 4 个空格的缩进，说明它们“从属”于上面的 `if`；最后一行没有缩进，就跳出了这个代码块。

**动手改一改**：把 `age` 改成 `16` 再运行——你会发现前两行消失了，只有没缩进的那一行还在输出。这就是缩进决定的“归属关系”。

> **规范**：Python 官方风格指南 PEP 8 建议**每一级缩进用 4 个空格**。VS Code 默认就是 4 空格缩进，直接按 Tab 键输入即可。切记不要空格和 Tab 混用，否则会报出难以排查的 `IndentationError`（缩进错误）。

## 规则三：注释——写给人看的说明

以 `#` 开头的内容是**注释（Comment）**。解释器会完全忽略它，注释只给人看：

```python
# 这一行是注释，不会被执行
print("Hello, Python!")  # 这也是注释，可以写在代码后面
```

注释的常见用途：

- 解释一段代码**为什么这么写**（思路、原因、注意事项）；
- 给长代码**做分节标记**，方便阅读；
- **暂时禁用**某行代码（俗称“注释掉”），调试时非常有用。

> **好习惯**：代码是写给人看的，只是顺便让机器执行。合理的注释能让未来的你和你的同事快速看懂这段代码。但也不要每行都注释——代码本身能表达清楚的，不必啰嗦。

## 规则四：严格区分大小写，只用英文字符

**1. Python 严格区分大小写（Case-sensitive）**。`name` 和 `Name` 是两个完全不同的名字，写错一个字母就会报错：

```python
print("Hello")   # ✅ 正确
Print("Hello")   # ❌ 报错！print 的 p 不能大写
```

**2. 代码中的符号必须是英文半角**。括号 `( )`、引号 `" "`、冒号 `:`、逗号 `,` 这些符号都必须用**英文半角**。中文符号长得几乎一样，但解释器完全不认识——这是初学者报错率最高的错误，没有之一：

```python
print（"Hello"）    # ❌ 用了中文括号（）
print(“Hello”)     # ❌ 用了中文引号“”
print("你好，世界")   # ✅ 中文出现在引号内部，完全没问题
```

注意最后一句：**中文内容可以写在引号里面，但不能把符号本身写成中文的**。

| 符号 | 英文半角 ✅ | 中文全角 ❌ |
| --- | --- | --- |
| 括号 | ( ) | （ ） |
| 引号 | " " 或 ' ' | “ ” ‘ ’ |
| 冒号 | : | ： |
| 逗号 | , | ， |

> **排查技巧**：如果报错信息里出现 `SyntaxError: invalid character '（' (U+FF08)`，括号里的字符编号就是中文标点的“身份证号”，说明你用了中文符号。写代码时把输入法切到英文模式，能避开绝大多数这类问题（切换方法见第 0 章）。

## 本章挑战作业

这一章能用的工具只有 `print`，但把简单工具用得精准，正是打基础。本作业**没有参考答案**——先自己挣扎 30 分钟再求助，卡住时回到对应小节重读。

**任务一：字符金字塔**。只用 `print` 和字符串，输出下面这个五行金字塔（星号数依次为 1、3、5、7、9，整体居中）：

```text
    *
   ***
  *****
 *******
*********
```

要求：

1. 每行代码末尾加一条注释，说明这是金字塔的第几行；
2. 完成后把金字塔改成**倒过来**的五层，体会“逐行执行”和你的书写顺序的关系。

**任务二：亲手制造一次报错**。故意把某一行的一个括号写成中文的，运行程序；把报错**最后一行**的内容抄进注释里保存，然后用一句话（注释形式）写下你对这个报错的理解，最后把代码修好。

> **提示**：每行由“空格 + 星号”组成。动手数一数：第 1 行有几个空格、第 2 行有几个？规律找出来了，五行就是五次 `print`。

**自测标准**：程序一次运行通过；金字塔居中对齐；注释里留有你与报错“交锋”的记录。

## 本章小结

- 代码自上而下逐行执行，书写顺序就是执行顺序。
- Python 用缩进（推荐 4 个空格）划分代码块，缩进本身就是语法。
- `#` 开头的内容是注释，只给人看、不被执行；写注释是好习惯。
- Python 严格区分大小写；代码符号必须用英文半角，中文只能出现在字符串内容里。
