# 输入与输出

## 让程序和用户对话

到目前为止，程序里用到的数据都是写死在代码里的。真正的程序要能**听**用户的输入，再把结果**说**给用户看。`input()` 和 `print()` 就是程序的耳朵和嘴。

## input：听用户说

```python
name = input("你叫什么名字？")
print("你好，" + name + "！")
```

`input()` 会让程序停下来等用户输入，括号里的提示语会显示在屏幕上，用户敲完回车，输入的内容就交还给了程序。

一个关键规则：**`input()` 返回的永远是字符串**——哪怕用户输入 `18`，程序拿到的也是 `"18"`。所以要参与数学运算，必须先用上一章的 `int()` 或 `float()` 转换：

```python
age = int(input("你几岁？"))
print("明年你就 " + str(age + 1) + " 岁了")
```

> **常见问题**：忘记转换就直接 `age + 1`，会报 `TypeError`，说字符串不能和整数相加——这个错我们在第五章见过，现在你知道它为什么总发生了。

## print 的两个小开关

```python
print("a", "b", "c")          # a b c —— 逗号分隔，默认用空格隔开
print("a", "b", sep="-")      # a-b —— sep 指定分隔符
print("加载中", end="")        # end 默认是换行，改成空串就不换行
print("完成")                  # 输出：加载中完成
```

## f-string：现代的输出方式

用 `+` 和 `str()` 拼句子既啰嗦又容易漏空格。**f-string** 是目前最推荐的写法——在字符串前加 `f`，用 `{}` 直接嵌入变量：

```python
name = "小明"
age = 18
print(f"我叫 {name}，今年 {age} 岁")
```

`{}` 里可以放任何表达式：

```python
print(f"明年 {age + 1} 岁")        # 明年 19 岁
print(f"1 加 2 等于 {1 + 2}")      # 1 加 2 等于 3
```

还能控制小数位数——`:.2f` 表示保留两位小数：

```python
pi = 3.14159
print(f"圆周率约为 {pi:.2f}")      # 圆周率约为 3.14
```

回忆第六章：处理浮点误差时我们用过 `round(0.1 + 0.2, 2)`；`{x:.2f}` 是在**显示层面**控制位数，更常用。

## 动手：BMI 计算器

综合运用本章和前几章的知识，做一个真正能用的小工具：

```python
height = float(input("请输入身高（米）："))
weight = float(input("请输入体重（千克）："))

bmi = weight / height ** 2

print(f"你的 BMI 是 {bmi:.2f}")

if bmi >= 24:
    print("偏重，注意饮食和运动")
elif bmi >= 18.5:
    print("正常，保持住")
else:
    print("偏轻，多吃点")
```

短短一段代码：运算优先级（`height ** 2`）、类型转换、f-string、条件语句全部上阵。输入身高 1.75、体重 65，看看结果是否约为 21.22。

## 本章挑战作业

**简易收银台**。让 BMI 计算器再进一步：这次要模拟真实收银，**没有参考答案**。

功能要求：

1. 依次输入**单价**和**数量**（都可能带小数），算出总价；
2. 优惠规则：总价满 100 元打**九折**，否则原价；
3. 最后输出一张三行小票：`商品单价：xx.xx 元`、`购买数量：x 件`、`实付金额：xx.xx 元`——金额全部保留两位小数。

要求：

- 金额显示必须用 f-string 的 `:.2f`，不许手动补 0；
- 折扣判断只用一组 `if / else`；
- 用两组数据自测：单价 3.5、数量 20（总价 70，不打折，实付 70.00）；单价 12.6、数量 10（总价 126，打折后实付 113.40）。

> **提示**：先算总价、再判断打折、最后输出——想清楚这三步的先后顺序再动笔。“打九折”就是乘以 0.9。如果 113.40 显示成了 113.4，说明你没用 `:.2f`。

**自测标准**：两组数据的结果分别是 70.00 和 113.40，小票三行一字不差。

## 本章小结

- `input()` 返回的永远是字符串，参与运算前必须用 `int()` / `float()` 转换。
- `print` 的 `sep` 参数指定分隔符，`end` 参数指定结尾（默认换行）。
- f-string 用 `f"..."` 配 `{}` 嵌入变量和表达式，`{x:.2f}` 控制小数位数，是最推荐的输出方式。
- BMI 计算器已经把输入、转换、运算、条件串成了完整程序。
