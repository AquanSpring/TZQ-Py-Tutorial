# 函数

## 把代码打包复用

同一段逻辑要在三个地方用，复制粘贴三遍——需求一改就要改三处，还容易漏。**函数（Function）**就是解决方案：把一段代码打包起来、起个名字、随取随用。

其实我们一直在用函数：`print()`、`input()`、`len()`、`int()` 都是别人写好的函数。这一章，轮到自己写了。

## 定义与调用

```python
def greet():
    print("你好！")
    print("欢迎学习 Python")

greet()     # 调用一次，执行一次
greet()
```

`def` 是 define（定义）的缩写。注意两点：

- 函数体同样靠**缩进**归属——第四章的规则二在这里继续生效；
- **定义不会执行，调用才执行**。定义只是“登记”了这个函数，`greet()` 才是真正让它跑起来。

顺带认识一个占位语句 **pass**——它什么都不做，专门用来撑住语法结构：

```python
def todo():
    pass          # 还没想好怎么写，先占个位，保证代码能运行
```

函数开头还可以放一段字符串，专门说明**这个函数是干什么的**，这叫**文档字符串（docstring）**：

```python
def add(a, b):
    """把两个数相加并返回结果。"""
    return a + b

print(add.__doc__)     # 把两个数相加并返回结果。
```

它和 `#` 注释的区别是：**文档字符串是程序的一部分**——可以用 `函数名.__doc__` 读出来，在交互模式里用 `help(add)` 也能看到。写给别人用的函数，值得加这么一句。

## 参数：给函数传数据

```python
def greet(name):
    print("你好，" + name + "！")

greet("小明")     # 你好，小明！
greet("小红")     # 你好，小红！
```

`name` 是**形参**（形式参数，函数内部的占位符），调用时传入的 `"小明"` 是**实参**（实际参数）。

参数可以有多个，还可以带**默认值**——不传就用默认，传了就覆盖：

```python
def greet(name, greeting="你好"):
    print(greeting + "，" + name + "！")

greet("小明")               # 你好，小明！
greet("小明", "早上好")      # 早上好，小明！
```

调用时还可以“指名道姓”地传参——**关键字参数**：

```python
greet(greeting="早上好", name="小明")    # 早上好，小明！—— 顺序随意
```

参数一多时，关键字参数能明显减少传错顺序的概率。

### 一个必须提前知道的坑：默认值别用可变对象

默认值只在**定义函数时算一次**，之后每次调用用的都是同一个。如果默认值是列表，就会看到很诡异的现象：

```python
def add_item(item, box=[]):      # ❌ 默认值是个列表
    box.append(item)
    return box

print(add_item("a"))    # ['a']
print(add_item("b"))    # ['a', 'b'] —— 上一次的结果还在！
```

原因：`box=[]` 只创建了一次，两次调用共用同一个列表。正确写法是把默认值设成 `None`，进了函数再建：

```python
def add_item(item, box=None):
    if box is None:
        box = []
    box.append(item)
    return box

print(add_item("a"))    # ['a']
print(add_item("b"))    # ['b'] —— 互不影响
```

一句话结论：**默认值用数字、字符串、`True / False`、`None` 这类不会变的东西**；要用列表或字典，就照上面的写法绕一下。

### 选学：接收任意多个参数（`*args` 和 `**kwargs`）

有时你写函数时并不知道调用者会传几个参数。在参数名前加一个 `*`，就能把**任意多个位置参数**收进一个元组：

```python
def total(*nums):
    print(nums)              # (1, 2, 3) —— 收到的是一个元组
    return sum(nums)

print(total(1, 2, 3))        # 6
print(total())               # 0 —— 一个都不传也行
```

加两个 `*` 收的则是**关键字参数**，装进一个字典：

```python
def show(**info):
    print(info)              # {'name': '小明', 'age': 18}
    for key, value in info.items():
        print(key, "=", value)

show(name="小明", age=18)
```

名字里的 `args` 和 `kwargs` 只是**约定俗成的叫法**（arguments / keyword arguments，第 0 章词典里就有），换成别的名字照样能跑——但大家都这么写，跟着写就好。

**反过来也能用**：调用时给列表或字典加上 `*` / `**`，就把它“拆开”当参数传进去：

```python
nums = [1, 2, 3]
print(total(*nums))          # 6 —— 等价于 total(1, 2, 3)

info = {"name": "小明", "age": 18}
show(**info)                 # 等价于 show(name="小明", age=18)
```

第 10 章学的 `x, y = (3, 5)` 是解包的一种，这里是它的另外两种用法。

## 返回值：把结果交回去

函数可以把计算结果**返回**给调用处：

```python
def add(a, b):
    return a + b

result = add(3, 5)     # 函数算出 8，“交回”给调用处，存进 result
print(result)          # 8
```

**`return` 和 `print` 是两回事**——这是新手最容易混淆的地方：

- `print()` 只是把结果显示在屏幕上，程序内部并没有拿到这个值；
- `return` 才是把结果真正交回调用处，可以存进变量、继续参与运算。

```python
def bad_add(a, b):
    print(a + b)        # 只打印，没有返回

x = bad_add(3, 5)       # 屏幕上显示 8，但 x 是 None！
print(x)                # None
```

没有 `return` 的函数，返回值是 `None`——第十一章 `get()` 里见过的那个“什么都没有”。

`return` 还能一次返回**多个值**——其实是打包成元组，配合第十章的解包接收：

```python
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([3, 1, 4, 1, 5])
print(low, high)        # 1 5
```

## 变量的作用范围

函数内部定义的变量，外面看不到：

```python
def test():
    inner = 42

test()
print(inner)          # ❌ NameError：外部不存在 inner
```

只在函数内部有效的变量叫**局部变量**。反过来，函数**可以读取**外面定义的变量。初学阶段记住一句话即可：函数自己的事自己了，别依赖外部的临时变量。

### 那想在函数里改外面的变量呢？

先看会发生什么。函数**可以读取**外面的变量，但一旦你在函数里给它**赋值**，Python 就认定你是在创建一个新的局部变量：

```python
count = 0

def add_one():
    count = count + 1      # ❌ UnboundLocalError

add_one()
```

报错说“局部变量 count 在赋值前被引用了”——因为函数里的 `count = ...` 让 Python 认定 `count` 是局部的，可它右边又想读这个还不存在的局部变量，于是卡住了。

真要改外面那个，得用 `global` 明确声明：

```python
count = 0

def add_one():
    global count           # 声明：我要改的是外面那个 count
    count = count + 1

add_one()
add_one()
print(count)               # 2
```

**但请把 `global` 当危险工具**：它让函数和外部的变量偷偷绑在一起，改一处可能影响很远的地方。更好的做法是让函数把结果**返回**出来，由调用方决定怎么用：

```python
count = 0

def add_one(n):
    return n + 1

count = add_one(count)
count = add_one(count)
print(count)               # 2
```

一句话原则：**能用参数和返回值解决，就不要用 `global`。** 这就是第 0 章词典里 `global / local`（全局 / 局部）那一行说的事。

## 动手：写一个判断偶数的函数

把第七章的奇偶判断打包成函数：

```python
def is_even(n):
    return n % 2 == 0

print(is_even(4))     # True
print(is_even(7))     # False
```

注意函数名的 `is` 前缀——返回布尔值的函数常用这种命名，调用起来像在读一句话：“4 是偶数吗？True”。

### 选学：函数调用自己（递归）

函数体里可以调用函数自己，这叫**递归**。有些问题这样写非常短——比如算阶乘（`5! = 5×4×3×2×1`）：

```python
def factorial(n):
    if n <= 1:                    # 1. 什么时候停（必须有！）
        return 1
    return n * factorial(n - 1)   # 2. 把问题缩小一点，再交给自己

print(factorial(5))     # 120
```

两个要点，缺一不可：

1. **终止条件**：`n <= 1` 时直接返回，不再调用自己。少了它就会无限递归下去，最后报 `RecursionError`；
2. **每一层都要往终止条件靠近**：这里是 `n - 1`。

递归能解决的问题，用循环基本也能解决（通常还更快）。初学阶段**能看懂、会写阶乘这种程度就够了**；真正非它不可的场合，是处理“自己里面还有自己”的结构——文件夹、菜单、JSON 数据，那是进阶篇的事。

## 本章挑战作业

**质数猎手**。质数是只能被 1 和它本身整除的数（2、3、5、7、11……）。这一题是函数 + 循环 + 条件的综合体，**没有参考答案**：

任务一：写一个函数 `is_prime(n)`，返回 `True` 或 `False`，表示 `n` 是不是质数。

任务二：用这个函数，打印 2 到 50 之间**所有的质数**。

要求：

1. `is_prime` 内部用循环：让 `n` 除以 2 到 n-1 之间的每个数，只要有一个能整除就**立刻 `return False`**——回忆本章“return 可以提前结束函数”；
2. 循环全部跑完都没找到因数，才 `return True`；
3. 特殊值要单独处理：`n` 小于 2 时直接返回 `False`（1 和 0 都不是质数）；
4. 任务二用 `for + range` 配合你的函数完成，输出一行一个质数。

> **提示**：任务二就是在“遍历候选者，挑出合格的”——和遍历列表挑出及格成绩是同一个套路，只不过“合格”的判断被你封装进了函数里。如果想验证对错：2 到 50 之间共有 15 个质数，最后一个是 47。

**自测标准**：`is_prime(2)` 为 `True`、`is_prime(9)` 为 `False`、`is_prime(1)` 为 `False`；任务二恰好输出 15 行。

## 本章小结

- `def` 定义函数，调用才执行；函数体靠缩进归属，没想好时用 `pass` 占位。
- 形参是占位符，实参是调用时传入的值；参数可带默认值，也可用“参数名=值”指名传参。
- `return` 把结果交回调用处，可以一次返回多个值；`print` 只是显示——没有 `return` 的函数返回 `None`。
- 函数内定义的是局部变量，外部访问不到。
- 返回布尔值的函数常用 `is_` 前缀命名。
