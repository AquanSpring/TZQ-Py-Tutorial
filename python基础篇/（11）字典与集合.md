# 字典与集合

## 按名字找，而不是按位置找

在电话簿里找“张三”，你不会从第一页一页数过去——直接翻到“张”开头的那页。**字典（Dictionary）**就是这样的容器：每个数据都挂着一个“名字”（**键，key**），通过键直接取值，而不是像列表那样靠位置。

## 字典的基本操作

```python
student = {"name": "小明", "age": 18}

print(student["name"])        # 小明 —— 按键取值
student["score"] = 95         # 键不存在 → 新增键值对
student["age"] = 19           # 键已存在 → 修改值
del student["score"]          # 删除这个键值对
print(len(student))           # 2 —— 键值对的个数
```

注意：花括号 `{}` 定义的是字典（键值对），方括号 `[]` 定义的是列表——但**访问元素时两者都用方括号**：`student["name"]`。

字典的键通常是字符串，值可以是任何类型，同一个字典里各值的类型也可以不同。

但键有个**硬性要求**：必须是**不可变**的类型。数字、字符串、元组都行，列表和字典不行：

```python
ok = {"name": "小明", (1, 2): "元组当键也可以"}    # ✅

bad = {[1, 2]: "列表当键"}      # ❌ TypeError: unhashable type: 'list'
```

原因：字典要靠键算出一个“位置”来快速查找，而可变的东西一旦改了内容，算出来的位置就对不上了。

### 还有几个字典方法

用到时查得到就行，先认识一下：

```python
student = {"name": "小明", "age": 18}

student.update({"age": 19, "score": 95})    # 批量新增或修改
print(student)                              # {'name': '小明', 'age': 19, 'score': 95}

print(student.pop("score"))                 # 95 —— 取出并删掉这个键
print(student)                              # {'name': '小明', 'age': 19}

print(student.setdefault("city", "北京"))    # 北京 —— 键不存在就设上默认值
print(student.setdefault("name", "小红"))    # 小明 —— 键已存在则不改，直接返回原值

student.clear()                             # 清空整本字典
print(student)                              # {}
```

## 安全访问：.get()

访问不存在的键会报错：

```python
print(student["phone"])       # ❌ KeyError
```

用 `.get()` 可以安全访问——键不存在时不报错，返回 `None`（表示“什么都没有”）：

```python
print(student.get("phone"))             # None
print(student.get("phone", "未填写"))    # 未填写 —— 第二个参数是默认值
```

判断“是不是 `None`”要用 `is`：`student.get("phone") is None`。

> **`is` 和 `==` 到底差在哪**：`==` 问的是“两个值**相等**吗”，`is` 问的是“是不是**同一个东西**”。判断“有没有值”用 `is None`，判断“两个值一不一样”用 `==`。完整的区别涉及内存，以后再展开；现在记住这个固定搭配就够：**判断 None 用 `is`**。

`in` 用在字典上判断的是**键**是否存在：`"age" in student` 是 `True`，`"phone" in student` 是 `False`。

## 遍历字典

```python
for key, value in student.items():
    print(key + "：" + str(value))
```

`items()` 把每个键值对拆成 `(键, 值)`，配合上一章的解包语法，一个循环同时拿到两个东西。只需要键或只需要值时，还有 `keys()` 和 `values()`：

```python
for name in student.keys():      # 只拿键
    print(name)

for value in student.values():   # 只拿值
    print(value)
```

## 实战：用字典计数

统计每个字符出现的次数——字典最经典的应用：

```python
text = "hello"

counts = {}
for ch in text:
    counts[ch] = counts.get(ch, 0) + 1

print(counts)        # {'h': 1, 'e': 1, 'l': 2, 'o': 1}
```

逐行读：字符串可以被 `for` 遍历（下一章细讲）；字符第一次出现时 `get` 返回默认值 0，加 1 后存入；再次出现时，在上次的基础上加 1。

## 集合：去重和判断利器

**集合（Set）**的特点：元素**不重复**、**无顺序**：

```python
nums = [1, 2, 2, 3, 3, 3]

unique = set(nums)         # 列表转集合，重复的自动消失
print(unique)              # {1, 2, 3}

print(2 in unique)         # True —— 成员判断非常快
unique.add(4)              # 添加元素
```

最常见的两个用途：**给列表去重**（`list(set(nums))` 转回列表）和**快速判断某个元素存在与否**。

> **必踩的坑**：空的花括号 `{}` 是**空字典**，不是空集合！想创建一个空集合，必须写 `set()`。

```python
a = {}          # 这是空字典
b = set()       # 这才是空集合
c = {1, 2, 3}   # 有元素时，花括号才是集合
```

判断一个变量到底是哪种类型，用第五章的 `type()` 一试便知。

### 集合真正好用的地方：集合运算

数学里的交、并、差，Python 直接给了一组运算符：

```python
a = {1, 2, 3, 4}
b = {3, 4, 5}

print(a | b)    # {1, 2, 3, 4, 5} —— 并集：两边都算上
print(a & b)    # {3, 4}          —— 交集：两边都有
print(a - b)    # {1, 2}          —— 差集：在 a 里但不在 b 里
print(a ^ b)    # {1, 2, 5}       —— 对称差：只在一方出现
```

举个真实场景：两个班都选了课的学生名单，想知道“两班都选的”“只在 A 班选的”，用 `&` 和 `-` 一行就出来了——换成列表写两层循环，得绕好几行。

## 嵌套容器：列表装字典

真实世界的数据几乎都长这样——一个列表，每个元素是一个字典：

```python
students = [
    {"name": "小明", "score": 90},
    {"name": "小红", "score": 85},
    {"name": "小刚", "score": 77},
]

for stu in students:
    print(f"{stu['name']} 考了 {stu['score']} 分")
```

读法：`students` 是列表，`students[0]` 取出第一个字典，`students[0]["name"]` 再取出里面的值。这种“两层容器”能表达一张表格，以后接触文件和接口数据时，见到的多半还是这个形状。

## 四大容器对比

| 容器 | 符号 | 特点 | 典型用途 |
| --- | --- | --- | --- |
| 列表 list | `[ ]` | 有序、可修改 | 一串会变化的数据 |
| 元组 tuple | `( )` | 有序、不可修改 | 固定不变的一组值 |
| 字典 dict | `{键: 值}` | 键值对、按键存取 | 按名字管理数据 |
| 集合 set | `{1, 2, 3}` | 不重复、无序 | 去重、成员判断（空集合要写 `set()`） |

## 选学：列表推导式

有一类循环特别常见——“把每个元素变换一下，收集成新列表”：

```python
scores = [90, 85, 77, 100, 66]

bonus = []
for s in scores:
    bonus.append(s + 5)

print(bonus)    # [95, 90, 82, 105, 71]
```

Python 为这个固定模式提供了紧凑写法——**列表推导式**：

```python
bonus = [s + 5 for s in scores]
print(bonus)    # [95, 90, 82, 105, 71]
```

还能带上 `if` 做**筛选**：

```python
passed = [s for s in scores if s >= 60]
print(passed)    # [90, 85, 77, 100]
```

读法：“对 `scores` 里的每个 `s`，若满足 `s >= 60`，就把 `s` 收进新列表”。本篇只要求**能看懂**别人的推导式；自己写时拿不准，就老老实实写 for 循环——两者完全等价，清晰永远优先。

同样的形状对字典和集合也成立，各看一个例子就够：

```python
# 字典推导式：把分数映射成等级
raw = [90, 55, 77]
levels = {s: ("及格" if s >= 60 else "不及格") for s in raw}
print(levels)    # {90: '及格', 55: '不及格', 77: '及格'}

# 集合推导式：收集所有出现过的首字母（集合自动去重，用 sorted 让输出顺序固定）
words = ["apple", "banana", "avocado"]
print(sorted({w[0] for w in words}))    # ['a', 'b']
```

顺带一个和推导式很搭的组合——`any()` 和 `all()`，它们吃的正是“一串 True / False”：

```python
scores = [90, 85, 77, 100, 66]

print(any(s >= 100 for s in scores))    # True  —— 有没有一个满足
print(all(s >= 60 for s in scores))     # True  —— 是不是全都满足
print(all(s >= 80 for s in scores))     # False —— 有一个不满足就不行
```

`any(s >= 100 for s in scores)` 里那对括号是**生成器表达式**：形状和推导式一样，只是不真的建出列表，边算边用（进阶篇细讲）。现在照抄形状就行。

## 本章挑战作业

**模拟登录系统**。真实软件的登录逻辑，你现在就有能力实现，**没有参考答案**：

```python
users = {"admin": "123456", "xiaoming": "abc888"}    # 用户名 → 密码
```

功能要求：

1. 循环提示输入用户名和密码，**最多允许尝试 3 次**；
2. 用户名密码都对：打印欢迎语，程序正常结束；
3. 三次都失败：打印“账号已锁定”，程序结束；
4. 每次失败后，提示还剩几次机会。

要求：

- 用 `while` + 计数器实现“最多三次”（回忆第八章的三要素）；
- 查用户必须用 `.get()` 或 `in`，不许直接 `users[name]`——想想为什么（想想不存在的用户名）；
- 用户不存在和密码错误，可以只提示“用户名或密码错误”一种信息（真实网站也这么干，这是安全考虑）。

> **提示**：主循环是 `while True` 还是“条件式 while”？两种都能写对，试着想清楚各自的退出条件。计数器每次失败 `+= 1`，等于 3 就锁定——把第七章的条件、第八章的循环、本章的字典串起来。

**自测标准**：连续输错 3 次触发锁定；第 2 次输对能正常进入且剩余次数提示正确（第一次失败后应提示“还剩 2 次机会”）。

## 本章小结

- 字典按“键”存取数据：`d[键]` 取值、赋值新增或修改、`del` 删除；`in` 判断的是键。
- 访问可能不存在的键用 `.get()`，避免 `KeyError`；判断 `None` 用 `is`。
- `items()` 遍历键值对，`keys()` / `values()` 只拿键或值；字典 + `get` 计数是经典套路。
- 集合天生去重，`in` 成员判断快；`list(set(...))` 是去重惯用法。
- 列表装字典的嵌套容器，能表达“表格”型数据。
- 推导式（列表 / 字典 / 集合）是“变换 + 收集”循环的紧凑写法，本篇要求看懂即可。
- 四大容器各有分工，选谁取决于数据的特点。
