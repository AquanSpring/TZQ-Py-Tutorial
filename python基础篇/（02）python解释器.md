# Python 解释器

## 什么是 Python 解释器？

可以将 **Python 解释器（Python Interpreter）** 简单理解为一个“实时翻译官”。

计算机的 CPU 只能读懂由 `0` 和 `1` 组成的机器指令（机器码），无法直接理解人类编写的 Python 源代码（如 `print("Hello")`）。解释器的核心职责，就是**将你编写的 Python 代码翻译成计算机硬件能够执行的机器语言，并执行它**。

> **概念澄清**：我们平时说的“Python 解释器”，默认指官方实现 **CPython**（由 C 语言编写）。除此之外还有 PyPy、Jython 等其他实现，初学阶段使用官方的 CPython 即可。

## 解释器是如何工作的？

当你运行一段 `.py` 代码时，解释器内部主要经历两个步骤：

```text
你的代码 (.py)
      ↓
[1. 编译为字节码]  →  生成与操作系统无关的中间代码（字节码）
      ↓
[2. 虚拟机执行]    →  Python 虚拟机（PVM）逐条将字节码翻译为 CPU 指令并运行
```

1. **编译为字节码（Bytecode）**：解释器先对源代码进行语法检查，再把它编译成一种更接近底层、但与操作系统无关的中间代码——字节码。字节码通常只缓存在内存中，被 `import` 导入的模块才会生成 `.pyc` 文件保存到磁盘。
2. **虚拟机执行（PVM，Python Virtual Machine）**：解释器内部的虚拟机逐条读取字节码，将其翻译成当前机器的 CPU 指令并立即执行。

### 解释型语言与编译型语言

按照传统的分类方式，编程语言有两大阵营：

- **编译型语言**（如 C、C++）：好比“先把整本书翻译完再出版”。代码必须先由编译器整体编译成机器码，之后才能运行。优点是运行速度快，缺点是换一个操作系统往往需要重新编译。
- **解释型语言**（如 Python）：好比“同声传译”，由解释器边翻译边执行。优点是跨平台、开发效率高。

需要说明的是，Python 并不是严格意义上的“逐行翻译”——它同样会先做一次整体编译（生成字节码），再交给虚拟机执行。因此更准确的说法是：**Python 是先编译为字节码、再解释执行的高级语言**。

## 安装并使用解释器

### 第一步：安装 Python

1. 访问官网下载页 [python.org/downloads](https://www.python.org/downloads/)，下载最新的 Python 3.x 安装包。
2. **Windows 用户注意**：在安装的第一个界面，务必勾选 **Add python.exe to PATH**（旧版安装器显示为 “Add Python 3.x to PATH”），否则无法在命令行中直接使用 `python` 命令。
3. macOS 用户按照安装向导操作即可，命令行中使用 `python3` 命令。

### 第二步：确认安装成功

打开命令行（Windows 的 CMD 或 PowerShell，macOS 的“终端”），输入以下命令：

```cmd
python --version
```

如果输出以 `Python 3.` 开头的版本号（如 `Python 3.14.0`），说明安装成功。具体小版本号不必和这里一致，只要是 3.x 就行。

> **常见问题**：提示 `“python” 不是内部或外部命令`？多数是安装时没有勾选 Add to PATH，重新运行安装程序并勾选该选项即可。

### 第三步：运行你的第一行代码

解释器提供了两种运行代码的方式，都可以让第一章的 `Hello, World!` 真正跑起来。

**方式一：交互模式（REPL）**。在命令行输入 `python`（macOS 输入 `python3`），看到 `>>>` 提示符后，输入一行代码就会立即执行一行，非常适合初学者随时试验。输入 `exit()` 可以退出。

```cmd
>>> print("Hello, World!")
Hello, World!
```

**方式二：运行脚本文件**。把代码保存为一个 `.py` 文件（如 `hello.py`），然后在命令行中执行：

```cmd
python hello.py
Hello, World!
```

交互模式适合做小实验、验证语法；而实际开发中，我们通常把代码写在 `.py` 文件里运行。

## 本章小结

- 解释器负责把 Python 源代码翻译成机器能够执行的指令；通常所说的解释器指官方实现 CPython。
- 工作流程：源代码 → 编译为字节码 → 由 Python 虚拟机（PVM）执行。
- Python 是“先编译为字节码、再解释执行”的语言，兼顾跨平台与开发效率。
- 运行代码有两种方式：交互模式（REPL）和运行 `.py` 脚本文件。
