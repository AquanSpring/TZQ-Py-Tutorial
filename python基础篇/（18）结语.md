# 结语：基础篇完结

## 你完成了什么

从第一章的那行 `Hello, World!`，到现在你能独立写出带函数、能保存数据的程序。逐项盘点，这些是你亲手完成的：

- 认识了 Python，亲手装好解释器和 VS Code，跑通了第一行代码（第 1~3 章）
- 掌握了代码的基本规则：逐行执行、缩进即语法、注释、只用英文字符（第 4 章）
- 会用变量记住数据，分得清 `int / float / str / bool`，会在类型之间转换（第 5 章）
- 会用算术、比较、逻辑运算符写出正确的表达式，知道浮点误差是怎么回事（第 6 章）
- 让程序学会了“选择”：`if / elif / else`、`and / or / not`、嵌套与短路（第 7 章）
- 让程序学会了“重复”：`while` 三要素、`for + range`、`break / continue`（第 8 章）
- 程序能“听”会说：`input`、`print`、f-string 格式化（第 9 章）
- 掌握了四大容器：列表、元组、字典、集合，知道什么数据用什么装（第 10~11 章）
- 会索引、切片、遍历字符串，用熟了 `strip / replace / split` 等高频方法（第 12 章）
- 会定义自己的函数：参数、默认值、`return`（第 13 章）
- 会 `import` 借力标准库和第三方库，会用 `pip` 装卸、用 venv 隔离项目依赖（第 14 章）
- 程序不再一碰就碎：`try / except` 接得住用户的乱输入（第 15 章）
- 结果不对时会自己排查：用 `print` 缩小范围，或用断点单步看真实的值（第 15 章）
- 数据能落盘长期保存：`open + with`、`r / w / a` 三种模式（第 16 章）
- 初识面向对象：会定义类、创建对象，理解 `self` 和继承（第 17 章）

每一章末尾的挑战作业，你都亲手做过——它们没有统一答案，因为答案在你自己敲出来的程序里。

## 毕业自查

基础篇的目标不是“看过”，而是**不查资料也能写出来**。对照下面这张清单逐条自测：能独立做到的，打个勾；做不到的，回到对应章节，把那一章的**挑战作业再做一遍**——重做旧题直到秒杀，是夯实基础最有效的方式。

| 自测项 | 达标标准 | 章节 |
| --- | --- | --- |
| 会读报错 | 看到 `TypeError` / `NameError` 能说出原因 | 4、15 |
| 变量与类型 | `18` 和 `"18"` 的区别张口就来 | 5 |
| 条件逻辑 | 能把一句“人话规则”翻译成布尔表达式 | 7 |
| 循环控制 | `while` 三要素、`for` 遍历、`break` 的时机 | 8 |
| 输入输出 | 记得 `input` 永远返回字符串，会用 f-string 控制小数位 | 9 |
| 选对容器 | 给一组真实数据，能选出 list / dict / set | 10~11 |
| 会写函数 | 参数、默认值、`return` 用得不假思索 | 13 |
| 程序健壮 | 用户乱输不崩溃、文件不存在不崩溃 | 15~16 |
| 会调试 | 程序不报错但结果不对时，能用 `print` 或断点找到真正出错的那一步 | 15 |
| 会定义类 | 独立写出一个带属性和方法的类 | 17 |
| 会拆问题 | 拿到小需求先想：什么数据、什么流程、要不要拆函数 | 贯穿全篇 |

全部打勾，你就不是“学过 Python”，而是“能用 Python 做事了”。

## 交作业前的易错点速查

下面每一条，正文里**都已经提醒过**——这里只是把它们集中起来，方便你卡住时对号入座。它不告诉你答案，只帮你定位自己踩的是哪个坑。

| 症状 | 大概率是这个坑 | 提醒在哪 |
| --- | --- | --- |
| 程序卡住不动 | 忘了更新循环条件（死循环），按 `Ctrl + C` 停 | 第 8 章 |
| 该循环 5 次却少了一次 | `range` 含头不含尾 | 第 8 章 |
| 多分支判断的结果不对 | `if / elif` 的顺序该从严到宽 | 第 7 章 |
| 字符串和数字相加报错 | `input()` 返回的永远是字符串 | 第 9 章 |
| 交换两个变量后有一个值丢了 | 覆盖之前没先暂存旧值 | 第 5 章 |
| 原列表被改得面目全非 | `b = a` 是别名不是副本，要复制用 `a[:]` | 第 10 章 |
| 访问字典的某个键就崩 | 键可能不存在，先用 `.get()` | 第 11 章 |
| 想追加却把文件清空了 | 用了 `"w"`，追加要用 `"a"` | 第 16 章 |
| 报错说语法不对，但看着没错 | 混进了中文标点，或漏了冒号 | 第 0、4 章 |
| 报错说名字没定义 | 变量名拼错，或函数内外的变量搞混了 | 第 13、15 章 |
| 循环里改了循环变量却不生效 | `for` 每轮都会按序列重新赋值 | 第 8 章 |

> **卡住了怎么办**：先读报错的**最后一行**（第 15 章有速查表），再回来对号入座；还不行就用第 15 章的调试办法——把中间变量 `print` 出来，看它是不是你以为的那个值。**不要靠猜，去看真实的值。**

## 下一步：往哪走

基础打好了，接下来有三件事值得按顺序做。

**第一件：把工具链补齐。** 这几样东西基础篇只点了名、没展开，但它们都是“会了立刻提高效率”的，以你现在的基础完全能自己看懂：

| 工具 | 解决什么问题 | 从哪入手 |
| --- | --- | --- |
| 调试器 | 程序不报错，但结果不对 | 第 15 章的“调试”一节，把 `F5` / `F10` 练熟 |
| 虚拟环境 venv | 不同项目的库版本互相打架 | 第 14 章的 venv 一节 |
| Git | 代码改坏了想回到昨天 | 先 `git init` / `git add` / `git commit` 三件套，原理后补 |
| 测试 | 改一处功能，怕弄坏另一处 | 先用 `assert` 起步，再学 `pytest` |

**第二件：继续进阶语法。** 装饰器、生成器、迭代器、类型注解、上下文管理器、并发……它们是“能写”和“写得优雅、写得快”之间的分水岭，本教程的**进阶篇**会接着讲。

**第三件：挑一条主线做下去。** 语法只是工具，真正的成长来自“用 Python 解决一个你真在乎的问题”：

- **数据分析**：NumPy、Pandas、Matplotlib——处理表格、画图、从数据里找规律；
- **Web 与爬虫**：requests、Flask / FastAPI——抓数据、写接口、搭网站；
- **自动化办公**：openpyxl、python-docx、pyautogui——批量处理 Excel、Word 和重复操作。

三条路都不必“先学完再动手”。挑一条，从一个最小的需求开始做。

> **一个忠告**：不要陷入“教程循环”——学完一本赶紧学下一本。**能力是在项目里长出来的，不是在教程里。**

## 完结语

基础篇到此**完结**。

所谓基础，不是“简单”，而是之后一切的承重墙——无论你将来写什么程序，用的都是这一篇里的东西。检验基础是否扎实的标准只有一个：**合上教程，你还能不能把每一章的挑战作业重新写出来**。

把旧作业重做一遍、给自己的旧程序加新功能，都是极好的巩固方式；哪天卡住了，随时回到这本教程里来。

祝你敲下的每一行代码，都算数。

—— 基础篇，完结。
