# 学前基础：开始之前的准备

## 为什么要有这一章

很多初学者担心：我英语不好，能学编程吗？**能。** 编程不需要你“会英语”，只需要你认识一百来个高频词——而且它们会在后面每一章反复出现，见两次自然就熟了。

反过来，这些词里有不少是**英文单词的缩写**（比如 `int` 是 integer 的缩写、`elif` 是 else if 的缩写），只认识缩写、不知道全称，记忆会事倍功半。本章把本教程会用到的英语一次性列出来，配好中文和缩写来源，当“小词典”用——**不用背，混个脸熟，随时回来查**。

除了单词，这一章还补几样上手之前最好知道的电脑小知识：中英文标点与输入法、键盘符号怎么打、文件扩展名、命令行。

## 四、关键字的本意（理解着记）

关键字是 Python 保留的英文词。**知道本意，语法就好记了**：

| 关键字 | 英文本意 | 作用 |
| --- | --- | --- |
| if | 如果 | 条件判断（第 7 章） |
| else | 否则 | 条件分支（第 7 章） |
| and / or / not | 且 / 或 / 非 | 逻辑组合（第 7 章） |
| in | 在……里 | 成员判断、遍历（第 8、10 章） |
| while | 当……的时候 | 条件循环（第 8 章） |
| for | 对于（每一个） | 遍历循环（第 8 章） |
| True / False | 真 / 假 | 布尔值（第 5 章） |
| None | 一个都没有 | 空值（第 11 章） |
| pass | 通过、跳过 | 占位语句（第 13 章） |
| import | 进口、引入 | 导入模块（第 14 章） |
| try / except | 尝试 / 把……排除在外 | 异常处理（第 15 章） |
| with | 带着 | 打开文件（第 16 章） |
| class | 类别 | 定义类（第 17 章） |
| lambda | λ（无名函数） | 临时用一次的小函数（第 10 章） |
| assert | 断言、断定 | 调试自测时的检查（第 15 章） |

比如 `3 in scores` 直译就是“3 在 scores 里吗？”——懂了本意，代码就能像句子一样读出来。

## 五、必要的电脑小知识

### 1. 中英文标点：先防住新手第一大坑

写代码必须用**英文半角标点**，而中文输入法打出来的是全角标点——肉眼几乎一样，计算机完全不认（第四章细讲）。先记住切换方法：

- **Windows**：单独按 `Shift` = 中英切换（多数输入法默认）；`Win + 空格` = 切换输入法；
- **macOS**：按 `Caps Lock`，或点菜单栏顶部的输入法图标切换。

写代码前，瞄一眼输入法状态栏是“英”还是“中”。中英标点对照：

| 中文（❌ 代码里不能用） | ， | 。 | ： | ； | （ ） | “ ” | ？！ |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **英文（✅ 代码用这个）** | `,` | `.` | `:` | `;` | `( )` | `" "` | `? !` |

### 3. 文件扩展名：别让 hello.py.txt 坑了你

- **扩展名**是文件名最后的“姓氏”：`.py` 是 Python 源代码、`.txt` 是文本文件、`.csv` 是表格数据、`.exe` 是可执行程序；
- Windows 默认**隐藏**扩展名——你新建的 `hello.py` 实际可能是 `hello.py.txt`，怎么运行都不对，还查不出原因。先让它显示出来：
  - **Win11**：文件资源管理器 → 顶部“查看” → “显示” → 勾选“文件扩展名”；
  - **Win10**：资源管理器 → “查看”选项卡 → 勾选“文件扩展名”；
- macOS 默认显示，不用设置。

### 4. 命令行：和计算机“打字对话”的窗口

第二章你会在命令行里敲出第一条命令。它是“用打字代替点击”的工具，先学会打开它：

- **Windows**：点开始菜单，直接输入 `cmd` 或 `powershell`，回车，出现 `C:\Users\你>` 这样的提示符；
- **macOS**：打开“终端”（Terminal），提示符以 `$` 结尾。

看到提示符就说明它在等你打字，不用怕。

## 本章小结

- 不用背单词：动词、名词、缩写、关键字四张表当词典用，遇到不认识的海量词，回这里查。
- 关键字都有英文本意，“理解本意 → 记住语法”，比死记硬背强得多。
- 三件小事提前做好：写代码切英文输入法、让扩展名显示出来、会打开命令行——能帮你在前几章少踩一半的坑。
