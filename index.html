1. 中英文标点：先防住新手第一大坑

写代码必须用英文半角标点，而中文输入法打出来的是全角标点——肉眼几乎一样，计算机完全不认（第四章细讲）。先记住切换方法：

  • Windows：单独按 Shift = 中英切换（多数输入法默认）；Win + 空格 = 切换输入法；
  • macOS：按 Caps Lock，或点菜单栏顶部的输入法图标切换。

写代码前，瞄一眼输入法状态栏是“英”还是“中”。中英标点对照：

3. 文件扩展名：别让 hello.py.txt 坑了你

  • 扩展名是文件名最后的“姓氏”：.py 是 Python 源代码、.txt 是文本文件、.csv 是表格数据、.exe 是可执行程序；
  • Windows 默认隐藏扩展名——你新建的 hello.py 实际可能是 hello.py.txt，怎么运行都不对，还查不出原因。先让它显示出来：
    • Win11：文件资源管理器 → 顶部“查看” → “显示” → 勾选“文件扩展名”；

Python 简介

认识 Python：优雅、强大的现代编程语言

Python 是一门高层次的通用编程语言，由荷兰程序员吉多·范罗苏姆（Guido van Rossum）于 1989 年圣诞节期间开始编写，并于 1991 年正式发布第一个版本。它的核心设计理念是“优雅、明确、简单”，语法非常贴近自然英语，代码具有极高的可读性。此外，Python 开源、免费，可以在 Windows、macOS、Linux 等主流操作系统上运行。

小趣闻：Python 这个名字并不是来自蟒蛇，而是取自 Guido 钟爱的英国喜剧团体 Monty Python（蒙提·派森）。他希望这门语言能像这部喜剧一样，让编程变得有趣。

为什么选择 Python？

  • 极简易读：使用缩进来定义代码块，省去了复杂的括号与分号，学习曲线平缓，是公认最适合初学者入门的编程语言之一。
  • 功能全面：拥有“开箱即用”的标准库，以及数以万计的第三方库（如 NumPy、Pandas、PyTorch、Django），能极大提高开发效率。
  • 应用极其广泛：
    • 人工智能与数据科学：机器学习、深度学习、数据挖掘与可视化的首选语言之一。
    • 网络爬虫与自动化办公：快速抓取网页数据，批量处理 Excel、PDF 与日常重复任务。
    • 后端与网络开发：驱动 Instagram、Reddit 等大型服务的后端系统。
    • 运维自动化与脚本编写：跨平台运行，快速搞定系统管理任务。

你的第一行代码

在 Python 中，打印经典的欢迎语句只需要一行：

print("Hello, World!")

这行代码的含义是：调用 Python 内置的 print() 函数，把括号中的内容输出到屏幕上。现在你还不能运行它，但已经能直观感受到 Python 语法的简洁——没有分号，没有大括号，读起来就像一句英语。

说明：本教程基于 Python 3.x（当前的主流版本）。早期的 Python 2 已于 2020 年停止维护，查阅资料时请注意区分版本。

本章小结

  • Python 由 Guido van Rossum 创建，设计理念是“优雅、明确、简单”。
  • 它语法简洁、生态丰富，广泛应用于人工智能、数据科学、Web 开发和自动化等领域。
  • 一行 print("Hello, World!") 就能完成输出，但“去哪里运行它”，正是下一章要解决的问题。

Python 解释器

什么是 Python 解释器？

可以将 Python 解释器（Python Interpreter） 简单理解为一个“实时翻译官”。

计算机的 CPU 只能读懂由 0 和 1 组成的机器指令（机器码），无法直接理解人类编写的 Python 源代码（如 print("Hello")）。解释器的核心职责，就是将你编写的 Python 代码翻译成计算机硬件能够执行的机器语言，并执行它。

概念澄清：我们平时说的“Python 解释器”，默认指官方实现 CPython（由 C 语言编写）。除此之外还有 PyPy、Jython 等其他实现，初学阶段使用官方的 CPython 即可。

解释器是如何工作的？

当你运行一段 .py 代码时，解释器内部主要经历两个步骤：

你的代码 (.py)
      ↓
[1. 编译为字节码]  →  生成与操作系统无关的中间代码（字节码）
      ↓
[2. 虚拟机执行]    →  Python 虚拟机（PVM）逐条将字节码翻译为 CPU 指令并运行
  1. 编译为字节码（Bytecode）：解释器先对源代码进行语法检查，再把它编译成一种更接近底层、但与操作系统无关的中间代码——字节码。字节码通常只缓存在内存中，被 import 导入的模块才会生成 .pyc 文件保存到磁盘。
  2. 虚拟机执行（PVM，Python Virtual Machine）：解释器内部的虚拟机逐条读取字节码，将其翻译成当前机器的 CPU 指令并立即执行。

解释型语言与编译型语言

按照传统的分类方式，编程语言有两大阵营：

  • 编译型语言（如 C、C++）：好比“先把整本书翻译完再出版”。代码必须先由编译器整体编译成机器码，之后才能运行。优点是运行速度快，缺点是换一个操作系统往往需要重新编译。
  • 解释型语言（如 Python）：好比“同声传译”，由解释器边翻译边执行。优点是跨平台、开发效率高。

需要说明的是，Python 并不是严格意义上的“逐行翻译”——它同样会先做一次整体编译（生成字节码），再交给虚拟机执行。因此更准确的说法是：Python 是先编译为字节码、再解释执行的高级语言。

安装并使用解释器

第一步：安装 Python

  1. 访问官网下载页 python.org/downloads，下载最新的 Python 3.x 安装包。
  2. Windows 用户注意：在安装的第一个界面，务必勾选 Add python.exe to PATH（旧版安装器显示为 “Add Python 3.x to PATH”），否则无法在命令行中直接使用 python 命令。
  3. macOS 用户按照安装向导操作即可，命令行中使用 python3 命令。

第二步：确认安装成功

打开命令行（Windows 的 CMD 或 PowerShell，macOS 的“终端”），输入以下命令：

python --version

如果输出以 Python 3. 开头的版本号（如 Python 3.14.0），说明安装成功。具体小版本号不必和这里一致，只要是 3.x 就行。

常见问题：提示 “python” 不是内部或外部命令？多数是安装时没有勾选 Add to PATH，重新运行安装程序并勾选该选项即可。

第三步：运行你的第一行代码

解释器提供了两种运行代码的方式，都可以让第一章的 Hello, World! 真正跑起来。

方式一：交互模式（REPL）。在命令行输入 python（macOS 输入 python3），看到 >>> 提示符后，输入一行代码就会立即执行一行，非常适合初学者随时试验。输入 exit() 可以退出。

>>> print("Hello, World!")
Hello, World!

方式二：运行脚本文件。把代码保存为一个 .py 文件（如 hello.py），然后在命令行中执行：

python hello.py
Hello, World!

交互模式适合做小实验、验证语法；而实际开发中，我们通常把代码写在 .py 文件里运行。

本章小结

  • 解释器负责把 Python 源代码翻译成机器能够执行的指令；通常所说的解释器指官方实现 CPython。
  • 工作流程：源代码 → 编译为字节码 → 由 Python 虚拟机（PVM）执行。
  • Python 是“先编译为字节码、再解释执行”的语言，兼顾跨平台与开发效率。
  • 运行代码有两种方式：交互模式（REPL）和运行 .py 脚本文件。

Python、解释器与 IDE 的区别

一个常见的困惑

学到这里，你可能已经见过一串相似的名字：Python、Python 解释器、PyCharm、VS Code……很多初学者都会卡在这些问题上：

  • “我下载安装的到底是 Python，还是 PyCharm？”
  • “装好了 PyCharm，为什么运行代码时还要让我选择‘解释器’？”
  • “Python 和 PyCharm，到底谁包含谁？”

这一章就把这三个最容易混淆的概念彻底分清。一句话概括：Python 是语言，解释器是真正运行代码的程序，IDE 是帮你编写代码的工具。

用一个比喻看懂三者

延续第二章“翻译官”的比喻，我们把这三者放进同一个场景：

  • Python 语言：相当于一门语言本身（比如英语的语法和词汇）。它是一套“约定”，规定了变量怎么定义、语句怎么写。你正在学习的，就是这门语言。
  • Python 解释器：第二章介绍过的“翻译官”，一个真正运行的程序（Windows 上就是 python.exe）。它能听懂用 Python 语言写成的代码并执行。从 python.org 下载的“Python 安装包”，装的其实就是它，外加标准库和 pip 等配套工具。
  • IDE（集成开发环境，Integrated Development Environment）：像给作家配的“智能写作台”。常见的 IDE 有 PyCharm、VS Code 等，提供语法高亮、自动补全、错误提示、一键运行等功能，让你写得更快、错得更少。本教程全程使用 VS Code：它免费开源、轻量流畅、插件生态丰富，既适合初学者，也是众多专业开发者的主力工具。

特别注意 IDE 的定位：IDE 负责“写”，解释器负责“跑”。IDE 本身并不会执行 Python 代码——当你点击“运行”按钮时，是 IDE 在背后替你调用了 Python 解释器。

你
  │ 在 IDE 中编写代码
  ↓

  ↓

常见疑问解答

Q1：装了 PyCharm，还需要单独安装 Python 吗？

需要。PyCharm 只是“写作台”，真正的“翻译官”（解释器）必须另外准备。这也是为什么新建 PyCharm 项目时它会让你“指定 Python 解释器（Interpreter）”——它就是在问：“你的翻译官在哪里？”（新版本 PyCharm 也提供帮你自动下载安装解释器的选项，但本质上两者是独立的软件。）

Q2：第二章只用命令行就把代码跑起来了，IDE 是不是必需品？

不是必需品。记事本加命令行理论上就能开发 Python，第二章你已经实践过了。但 IDE 的补全、纠错、调试功能能大幅提高效率，实际开发中几乎人人都在用。

Q3：安装 Python 后，开始菜单里出现的 IDLE 是什么？

IDLE 是随解释器一起安装的简易 IDE，功能比较简单。可以拿来尝鲜，但很快你就会想换用更强大的 IDE——本教程推荐 VS Code。

本章小结

  • Python 是一门语言（一套语法约定），解释器是执行它的程序，IDE 是辅助编写的工具，三者层次分明。
  • IDE 不执行代码，它只是在你点击“运行”时调用解释器。
  • 从 python.org 安装的是解释器及配套工具；PyCharm、VS Code 需要单独安装，并指向已装好的解释器。
  • 没有 IDE 也能写 Python，但没有解释器代码一定跑不起来。
  • 本教程使用 VS Code 作为开发工具，请在下方的“动手环节”中完成安装与配置。

代码的基本结构与规则

开始之前

上一章的“动手环节”里，你已经装好了 VS Code 并配置好 Python 解释器。从这一章起，我们正式开始写代码。

写代码就像学一门新语言，先要掌握它的基本“游戏规则”。本章的四条规则会贯穿你整个编程生涯，请务必亲手把每个例子敲一遍——编程是练出来的，不是看出来的。

规则一：代码自上而下，逐行执行

程序默认从第一行开始，一行接一行地往下执行：上一行执行完毕，才会执行下一行。这建立了程序的时序概念——代码的书写顺序，就是它的执行顺序。

在 VS Code 中新建文件 demo.py，输入以下代码并运行：

print("我先执行")
print("我后执行")
print("我最后执行")

运行结果：

我先执行
我后执行
我最后执行

输出的顺序和代码的书写顺序完全一致。试着把三行代码调换位置再运行一次，观察输出顺序的变化，你会更直观地感受到“逐行执行”。

提前说明：以后学到条件语句和循环，你会发现代码也可以“跳着执行”或“重复执行”，但“从上到下”始终是最基本的默认规则。

规则二：缩进（Indentation）即语法

大多数语言用花括号 {} 来划分代码块，Python 不一样——它用缩进来表示代码的层次和归属。缩进相同的连续语句，属于同一个代码块。

先看一个例子（if 语句现在不用完全理解，后面章节会详细讲，这里只感受缩进的作用）：

age = 18

if age >= 18:
    print("你已成年")      # 缩进了 4 格：属于 if，条件成立才执行
    print("欢迎注册")      # 缩进了 4 格：属于 if，条件成立才执行

print("我不受 if 控制")     # 没有缩进：不属于 if，总会执行

前两个 print 前面有 4 个空格的缩进，说明它们“从属”于上面的 if；最后一行没有缩进，就跳出了这个代码块。

动手改一改：把 age 改成 16 再运行——你会发现前两行消失了，只有没缩进的那一行还在输出。这就是缩进决定的“归属关系”。

规范：Python 官方风格指南 PEP 8 建议每一级缩进用 4 个空格。VS Code 默认就是 4 空格缩进，直接按 Tab 键输入即可。切记不要空格和 Tab 混用，否则会报出难以排查的 IndentationError（缩进错误）。

规则三：注释——写给人看的说明

以 # 开头的内容是注释（Comment）。解释器会完全忽略它，注释只给人看：

# 这一行是注释，不会被执行
print("Hello, Python!")  # 这也是注释，可以写在代码后面

注释的常见用途：

  • 解释一段代码为什么这么写（思路、原因、注意事项）；
  • 给长代码做分节标记，方便阅读；
  • 暂时禁用某行代码（俗称“注释掉”），调试时非常有用。

好习惯：代码是写给人看的，只是顺便让机器执行。合理的注释能让未来的你和你的同事快速看懂这段代码。但也不要每行都注释——代码本身能表达清楚的，不必啰嗦。

规则四：严格区分大小写，只用英文字符

1. Python 严格区分大小写（Case-sensitive）。name 和 Name 是两个完全不同的名字，写错一个字母就会报错：

print("Hello")   # ✅ 正确
Print("Hello")   # ❌ 报错！print 的 p 不能大写

2. 代码中的符号必须是英文半角。括号 ( )、引号 " "、冒号 :、逗号 , 这些符号都必须用英文半角。中文符号长得几乎一样，但解释器完全不认识——这是初学者报错率最高的错误，没有之一：

print（"Hello"）    # ❌ 用了中文括号（）
print(“Hello”)     # ❌ 用了中文引号“”
print("你好，世界")   # ✅ 中文出现在引号内部，完全没问题

注意最后一句：中文内容可以写在引号里面，但不能把符号本身写成中文的。

符号英文半角 ✅中文全角 ❌
括号( )（ ）
引号" " 或 ' '“ ” ‘ ’
冒号:：
逗号,，

排查技巧：如果报错信息里出现 SyntaxError: invalid character '（' (U+FF08)，括号里的字符编号就是中文标点的“身份证号”，说明你用了中文符号。写代码时把输入法切到英文模式，能避开绝大多数这类问题（切换方法见第 0 章）。

变量与数据类型

为什么需要变量？

到目前为止，我们的代码都是“执行完就忘”：print 输出一句话，程序结束，什么也没留下。而真实的程序需要记住数据——你的游戏等级、购物车里的商品、银行账户的余额。

变量（Variable） 就是程序用来“记住”数据的工具。这一章我们学习两件事：怎么用变量记住数据，以及数据本身有哪些“种类”（数据类型）。

什么是变量

可以把变量理解成贴在数据上的标签：数据本身放在内存里，变量名就是指向它的标签，你通过标签随时找到这份数据。

给变量赋值的写法是：变量名 = 数据，中间的 = 叫赋值号：

name = "小明"    # 把字符串 "小明" 贴上 name 这个标签
age = 18         # 把整数 18 贴上 age 这个标签

print(name)      # 小明
print(age)       # 18

注意：= 不是数学里的“相等”，而是“把右边的值赋给左边”。读作“把 18 赋给 age”，而不是“age 等于 18”。

变量最大的特点是“变”——它的值可以随时更新：

score = 60
score = score + 40    # 先算右边的 60 + 40，再把结果 100 赋回 score
print(score)          # 100

第二行是理解赋值的关键：Python 总是先算等号右边，再把结果赋给左边。如果 = 真的是“相等”，这行代码在数学上根本不成立——这正是它不是等号的证明。

给变量起名字

变量名不是随便起的，它有两套约束。

硬性规则（违反会直接报错）：

  1. 只能由字母、数字、下划线组成，如 name、age2、student_score；
  2. 不能以数字开头（2name ❌，name2 ✅）；
  3. 不能使用 Python 的关键字（if、for、while、class 等 30 多个被语言本身占用的词）；
  4. 严格区分大小写——Age 和 age 是两个不同的变量（还记得第四章的规则四吗？）。

软性讲究（不违反会更好）：

  • 见名知意：存学生年龄就叫 student_age，别叫 a、x1；
  • 多个单词用下划线连接：user_name、total_price，这是 Python 官方推荐的风格；
  • 建议用英文单词，避免拼音缩写带来的歧义。

还有一条常见约定：不该被修改的量用全大写命名，如 PI = 3.14159、MAX_RETRY = 3。Python 并没有真正的“常量”，全大写只是提醒读代码的人：请别改它。

动手试一试：故意输入 2name = 1 并运行，观察报错信息。学会读懂 SyntaxError，是你排查代码问题的第一课。

常用的数据类型

数据是有“种类”的，Python 会自动识别最常见的四种：

类型名称例子一句话说明
int整数18、-5、0不带小数点的数
float浮点数3.14、-0.5带小数点的数
str字符串"hello"、"你好"引号包住的一串字符
bool布尔True、False只有两个值，表示“真/假”

用内置的 type() 函数可以查看任何数据的类型：

print(type(18))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type("hello"))    # <class 'str'>
print(type(True))       # <class 'bool'>

两个值得注意的细节：

  • 布尔值的 True 和 False 首字母必须大写——又一次呼应第四章：Python 严格区分大小写。
  • 引号决定一切：18 是整数，"18" 是字符串。长得一样，类型完全不同，这也正是下面类型转换存在的原因。

说明：这四种是起步阶段最常用的类型。后面章节还会遇到列表、字典等能装下更多数据的“容器型”类型，现在先把这四种用熟。

类型转换：在类型之间搭桥

不同类型的值不能随意混用。比如把字符串和整数直接相加，程序会报错：

print("5" + 5)    # ❌ TypeError：字符串只能和字符串拼接，不能拼接整数

解决的办法是类型转换，Python 提供了三个最常用的转换函数：

int("5")       # 字符串 → 整数，得到 5
float("3.14")  # 字符串 → 浮点数，得到 3.14
str(100)       # 整数 → 字符串，得到 "100"

一个最实用的场景——先把字符串转成数字，再做数学运算：

age = "18"          # 此时 age 是字符串
age = int(age)      # 转换成整数
print(age + 1)      # 19 ✅

反过来，想把数字拼进一句话里，就要先用 str() 把数字转成字符串：

age = 18
print("我今年 " + str(age) + " 岁")    # 我今年 18 岁

常见问题："5" + 5 报错？先看错误类型 TypeError（类型错误），再读提示信息——它会告诉你哪两种类型出了问题。看懂报错，比背答案更重要。

  • 命名有硬规则（字母/数字/下划线、不数字开头、区分大小写、避开关键字）和软讲究（见名知意、下划线连接）。
  • 基础数据类型四种：int、float、str、bool，用 type() 查看类型。
  • 18 和 "18" 类型不同；int()、float()、str() 负责在类型之间转换。

运算符与表达式

让程序开始“算”

上一章我们让程序“记住”了数据，这一章让它“干活”——运算。这本来就是计算机最擅长的事。

先认识两个词：运算符（Operator）是 +、-、* 这些运算符号；把数据和运算符组合起来、能算出一个结果的式子叫表达式（Expression）。表达式算出的结果可以存进变量：

price = 5
count = 3
total = price * count    # 右边是一个表达式，算出 15 赋给 total
print(total)             # 15

算术运算符

Python 提供了 7 个算术运算符，前三个和数学完全一样，后四个是编程特有的：

运算符含义例子结果
+加7 + 29
-减7 - 25
*乘7 * 214
/除7 / 23.5
//整除（只留整数部分）7 // 23
%取余7 % 21
**幂（乘方）7 ** 249

三个要点：

  • / 的结果永远是浮点数：10 / 2 得到的是 5.0，不是 5——呼应上一章的类型知识。
  • % 取余非常实用：判断奇偶（n % 2 结果是 0 就是偶数）、提取个位（123 % 10 得到 3）都靠它。
  • // 是“向下取整”的整除：正数时就是“扔掉小数部分”，但负数时会往更小的方向取，如 -7 // 2 是 -4。初学阶段记住正数用法即可，见到负数结果时想起这条。

动手试一试：在 VS Code 里把这个表格逐行敲一遍——先口算，再运行验证。全对说明你已经掌握了。

运算优先级

表达式里有多个运算符时，运算顺序和数学一致：

  1. 括号最优先；
  2. 其次是幂（**）；
  3. 再是乘、除、整除、取余；
  4. 最后是加、减；同级运算从左到右。
print(2 + 3 * 4)     # 14，先乘后加
print((2 + 3) * 4)   # 20，括号改变顺序

建议：不确定顺序时，加括号。括号既不会算错，还能让读代码的人一眼看懂你的意图。

字符串也能“运算”

+ 和 * 对字符串同样有效，但含义变了：

first = "Hello, "
second = "World!"
print(first + second)    # Hello, World!  —— + 是拼接

print("-" * 20)          # -------------------- —— * 是重复
print("Ha" * 3)          # HaHaHa

注意：+ 的两边必须是同是字符串——第五章 "5" + 5 报的 TypeError 就是这个原因，需要先转换类型再运算。

比较运算符：结果是“真 / 假”

比较运算符用来比较两个值的关系，运算结果是一个布尔值——上一章学的 bool 类型，在这里正式派上用场：

运算符含义例子结果
==等于7 == 7True
!=不等于7 != 7False
>大于7 > 2True
<小于7 < 2False
>=大于等于7 >= 7True
<=小于等于7 <= 2False
age = 18
print(age >= 18)    # True
print(age == 20)    # False

本章最重要的区别：= 是赋值（把值存进变量），== 是比较（问两者是否相等）。写成 if x = 5 之类的错误，大多源于把这两个弄混了。

Python 还支持数学里的连写比较：18 <= age <= 60 等价于 age >= 18 and age <= 60（and 下一章细讲），判断“区间”时非常好用。

顺带一提，字符串也能比较大小（按字符编码顺序），这个规则用到时再细讲，现在先不深究。

简写运算符：+= 家族

“在原值基础上更新”是高频操作，Python 提供了简写形式：

count = 0
count += 1    # 等价于 count = count + 1，count 变成 1
count += 1    # count 变成 2
print(count)  # 2

-=、*=、/=、//= 都是同样的道理。其中 += 出现频率最高，务必熟练。

一个著名的坑：浮点数误差

运行下面这行代码，结果可能出乎你的意料：

print(0.1 + 0.2)    # 0.30000000000000004 ？

这不是 bug，也不是你写错了——计算机内部用二进制存储小数，而很多十进制小数（比如 0.1）无法被二进制精确表示，于是产生微小的误差。所有编程语言都有这个现象。

初学阶段的应对：用 round() 把结果保留到指定位数，如 round(0.1 + 0.2, 2) 得到 0.3。

注意：round() 并不是严格的“四舍五入”，它用的是“四舍六入五成双”——round(2.5) 得到的是 2，不是 3；round(3.5) 才得到 4。所以它适合用来收拾显示上的小尾巴，不适合做精确计算。以后涉及金额等场景，我们再介绍专门的 Decimal 模块。

本章挑战作业

一道流传千年的算术题，只用变量和运算符（不许用 if——下一章才学），没有参考答案：

鸡兔同笼。笼中有 35 个头、94 只脚。设鸡有 chickens 只、兔有 rabbits 只，用表达式算出它们各是多少只，并 print 出结果。

要求：

  1. 先把解题思路写在注释里（用中文描述你的算式逻辑），再翻译成代码；
  2. 结果必须由表达式算出来，不许直接写 chickens = 23；
  3. 用 print 输出两行验证：头数之和是否为 35，脚数之和是否为 94（提示：比较表达式会输出 True/False，回忆本章的比较运算符）。

提示：假设 35 只全部是鸡，脚只有 70 只，比实际的 94 少了 24 只。每把一只鸡换成兔，脚就多 2 只——24 里有几个 2，就有几只兔。把这个思路用 -、*、// 翻译成表达式。

自测标准：输出鸡 23 只、兔 12 只，且两行验证都是 True。

本章小结

  • 表达式 = 数据 + 运算符，总能算出一个结果；结果常被赋给变量。
  • 七个算术运算符：+ - * / // % **；/ 的结果永远是浮点数。
  • 优先级：括号 > 幂 > 乘除 > 加减，不确定就加括号。
  • 字符串支持 +（拼接）和 *（重复），但 + 两边必须都是字符串。
  • 比较运算符的结果是布尔值；== 是比较，= 是赋值。
  • += 等简写运算符让“在原值上更新”更简洁。
  • 浮点误差源于二进制存储，属正常现象，可用 round() 缓解。

条件语句

程序需要“看情况办事”

到目前为止，我们的代码只会一条道走到黑：从上到下逐行执行，从不拐弯。但真实的任务处处需要选择：登录时，密码对了才放行；购物结算时，满 99 元才免运费；过马路时，绿灯才能走。

条件语句（Conditional Statement）就是让程序学会选择的结构：某个条件成立时，才执行某段代码。还记得第四章那个“现在不用完全理解”的 if 吗？现在正式揭开它的面纱——你已经准备好了比较运算符和缩进这两块拼图。

if：条件成立才执行

age = 18

if age >= 18:
    print("你已成年")
    print("欢迎注册")

print("程序结束")

解剖一下语法结构：

  • if 后面跟一个条件——通常就是第六章学的比较表达式，结果只有 True 或 False；
  • 行尾的冒号 : 不能少（英文半角，第四章规则四）；
  • 冒号下一行缩进 4 格的内容，是归属于 if 的代码块——第四章说过 Python 用缩进组织代码块，在这里终于用上了；
  • 条件为 True：执行代码块；为 False：整个代码块被跳过。

动手试一试：运行后把 age 改成 16 再运行——中间两行消失了，只有“程序结束”还在输出。

else：两种情况，必走其一

if 只处理了“成立”的情况，“不成立”时干什么？用 else：

age = 16

if age >= 18:
    print("你已成年")
else:
    print("你还未成年")

else 表示“其余情况”，它本身不带条件，直接跟冒号。if 和 else 二选一，必然走其中一条路。

elif：多种情况依次判断

两种情况不够用怎么办？用 elif（else if 的缩写）串起更多分支：

score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")

判断规则：自上而下逐个检查条件，命中一个就执行它，然后跳过其余所有分支。

  • score 是 85：>= 90 不成立，>= 80 成立 → 输出“良好”，后面的分支全部跳过；
  • 动手试一试：把 score 改成 95、59、100 各运行一次，先猜结果，再验证。

注意顺序：如果反过来把“及格”放在最前面判断，85 分会先命中“及格”，永远轮不到“良好”。多分支要从严到宽（从特殊到一般）排列，才能保证逻辑正确。

and、or、not：条件的组合

单个条件常常不够用，比如“年满 18 并且持票才能入场”，需要把多个条件组合起来：

运算符含义何时成立
and并且两边都为 True
or或者两边至少一个为 True
not取反True 变 False，False 变 True
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("可以入场")

vip = False
amount = 120

if vip or amount >= 99:
    print("免运费")

if not vip:
    print("开通会员享专属折扣")

提示：不要写 if has_ticket == True: 这样的冗余代码——has_ticket 本身就是布尔值，直接把它放进条件即可：if has_ticket:。

三个运算符的优先级是 not → and → or；和算术运算一样，拿不准就加括号。

顺带一提：短路。and 和 or 有个很实用的脾气——结果一旦确定，右边的表达式就根本不会被计算：

b = 0
if b != 0 and 10 / b > 1:     # 左边为假，右边的 10 / b 压根不会算，所以不会报 ZeroDivisionError
    print("成立")

这个脾气正好可以用来“先挡住危险，再动手”，也可以省掉一个 if：

name = input("你的名字：") or "游客"     # 输入为空（假值）时，取右边的“游客”

上面这行是常见惯用法：A or B 读作“A 有内容就用 A，否则用 B”。它依赖的正是下面这条真假规则。

哪些值是“真”，哪些是“假”

其实不止布尔值——任何值都能放进 if 当条件，Python 会自动按“真 / 假”来解释：

  • 当作假的只有少数几个：0、0.0、""（空字符串）、空列表 []、空元组 ()、空字典 {}、空集合 set()、None；
  • 其余的值一律当真：非零数字、非空字符串、非空容器。

所以 if name: 就能判断“名字填了没有”——空字符串算“假”。这个规则在处理容器时特别顺手：“列表非空”直接写 if items: 就行，后面两章会反复用到。

嵌套：if 里面还能有 if

代码块里可以再放新的 if，只需再缩进一层：

age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("可以入场")
    else:
        print("请先购票")
else:
    print("未满 18 岁禁止入场")

嵌套的层次完全靠缩进区分——缩进越深，归属越内层。但要提醒：嵌套不宜太深，超过两层往往可以用 and 合并条件来简化，代码更好读。

顺带一提：如果只是“二选一地定一个值”，Python 还有更紧凑的写法——条件表达式：

age = 20
tag = "成年" if age >= 18 else "未成年"
print(tag)    # 成年

读作“如果条件成立取 if 前面的值，否则取 else 后面的值”。它只能做“两选一赋值”，代替不了执行多条语句的 if/else 结构。

新手常见的三个坑

  1. 忘记冒号：if age >= 18 后面少了 :，立刻报 SyntaxError。
  2. = 和 == 混用：条件里写 age = 18（赋值）而不是 age == 18（比较）——第六章的重点，这里再强调一次。
  3. 缩进不一致：同一个代码块有的缩 4 格、有的缩 2 格，会报 IndentationError。

本章挑战作业

闰年判断。这是条件逻辑的经典练习，没有参考答案。

规则：某一年是闰年，当且仅当满足以下任意一条：

  • 能被 4 整除，且不能被 100 整除；
  • 能被 400 整除。

写一个程序，对变量 year 判断并输出“是闰年”或“不是闰年”。

要求：

  1. 只用一组 if / elif / else（可以配合 and / or / not），不许多次单独 if；
  2. 依次用 2023、2024、1900、2000 四个年份测试，先把你的预测写在注释里，再运行验证——1900 和 2000 这两个最容易翻车；
  3. 整除判断用 %：year % 4 == 0 表示能被 4 整除。

提示：把“任意一条满足”翻译成 or，把“能被 4 整除且不能被 100 整除”翻译成 and + not。想不清楚时，先把两条规则用中文写完整，再逐词替换成运算符。

自测标准：四个年份的判断全部正确（2023 平年、2024 闰年、1900 平年、2000 闰年）。如果全对了，说明你已经能把一条“人话规则”精确翻译成布尔逻辑——这是条件语句的真功夫。

本章小结

  • if 条件成立才执行代码块；else 处理其余情况；elif 串起多分支，自上而下命中即停。
  • 多分支条件要从严到宽排列，否则会被前面的分支“截胡”。
  • and / or / not 用于组合条件；布尔变量可以直接作为条件；and / or 会短路，右边可能根本不执行。
  • if 可以嵌套，靠缩进区分层次，但不宜嵌套太深。
  • 三大坑：忘冒号、= 与 == 混用、缩进不一致。

循环语句

为什么需要循环？

要打印“学习 Python 第 1 天”到“第 100 天”——复制粘贴一百行 print？程序员的答案永远是：让机器重复。循环（Loop）就是让一段代码反复执行的结构，Python 提供两种：while 和 for。

while：条件成立就一直做

count = 1

while count <= 5:
    print("这是第 " + str(count) + " 次循环")
    count += 1

print("循环结束")

一个 while 循环由三要素构成，缺一不可：

  1. 初始化：count = 1，循环开始前的准备；
  2. 条件：count <= 5，每轮开始前检查，为 True 才继续；
  3. 更新：count += 1，让条件最终能变成 False。

如果忘了更新会怎样？count 永远是 1，条件永远成立，程序陷入死循环。在终端里按 Ctrl + C（第 0 章提过的那把“救命键”）可以强制停止程序。

动手试一试：把 count += 1 注释掉（回忆第四章的注释），运行，体验死循环，然后用 Ctrl + C 停掉它。

提示：while True: 是“故意死循环”的固定写法，配合 break 实现“一直运行，直到某件事发生”。这是菜单式程序的通用骨架，本篇稍后的挑战作业里你就会用到。

for 与 range：按次数循环

已知重复次数时，for 配合 range() 更方便：

for i in range(5):
    print(i)

输出：

0
1
2
3
4

变量 i 依次取到 range 生成的每一个整数：

写法生成的数
range(5)0, 1, 2, 3, 4
range(1, 6)1, 2, 3, 4, 5
range(1, 10, 2)1, 3, 5, 7, 9

注意上界取不到：range(1, 6) 到 5 就停了，这个“含头不含尾”的规则后面还会反复遇到。

步长还可以是负数：range(5, 0, -1) 生成 5、4、3、2、1——倒着数就靠它。

for 的本意是遍历——依次取出一个序列里的每一项。它能遍历的不只是 range，列表、字符串都行，后面两章会大量用到。

break 与 continue：控制循环走向

  • break：立即终止整个循环；
  • continue：跳过本轮，直接进入下一轮。
for i in range(1, 6):
    if i == 3:
        break        # 换成 continue 对比效果
    print(i)

用 break 输出 1、2；换成 continue 输出 1、2、4、5。

动手试一试：先猜结果，再运行验证。

嵌套循环：循环里套循环

for i in range(1, 4):
    line = ""
    for j in range(1, 4):
        line = line + str(i) + "×" + str(j) + "  "
    print(line)

输出：

1×1  1×2  1×3  
2×1  2×2  2×3  
3×1  3×2  3×3

外层每走一步，内层要跑完一整轮——想象钟表：分针（外层）每走一格，秒针（内层）要走完一圈。

动手改一改：把内层改成 range(1, i + 1)，你会得到一个三角形——这正是九九乘法表的结构，试试把它补全。

新手常见的坑

  1. 死循环：忘了更新条件变量，程序卡住——Ctrl + C 停止；
  2. 差一错误：想要 1~5 却写成 range(1, 5)，少了一个 5；
  3. 循环里手动改循环变量：在 for i in range(5) 里修改 i 是徒劳的，下一轮它会按序列重置。

本章挑战作业

FizzBuzz。这是世界范围内流传最广的入门筛选题，很多公司的面试都用它——现在轮到你。规则：遍历 1 到 100 的所有整数，没有参考答案：

  • 能被 3 整除的，打印 Fizz；
  • 能被 5 整除的，打印 Buzz；
  • 既能被 3 又能被 5 整除的，打印 FizzBuzz；
  • 其余的，打印数字本身。

要求：

  1. 只用一组 for + if / elif / else；
  2. 从 1 到 100 每个数恰好输出一行，不多不少；
  3. 写完后自查三个位置：第 15 行应输出 FizzBuzz，第 9 行应输出 Fizz，第 10 行应输出 Buzz。

提示：最容易错的是分支的顺序。回想第七章的“从严到宽”——“既是 3 又是 5 的倍数”这个条件最苛刻，它应该排在 if 链的第几位？整除判断用 %（第六章）。

自测标准：三处抽查位置全部正确、总输出恰好 100 行。全对说明你已经能把循环和条件组合成完整的判断流程——这是流程控制的毕业题。

本章小结

  • while 由三要素构成：初始化、条件、更新；忘了更新就是死循环。
  • for + range() 按次数循环，range 含头不含尾。
  • break 终止整个循环，continue 跳过本轮。
  • 循环可以嵌套，外层一步、内层一轮。
  • for 的本质是遍历序列——为后面两章的容器做好了准备。

输入与输出

让程序和用户对话

到目前为止，程序里用到的数据都是写死在代码里的。真正的程序要能听用户的输入，再把结果说给用户看。input() 和 print() 就是程序的耳朵和嘴。

input：听用户说

name = input("你叫什么名字？")
print("你好，" + name + "！")

input() 会让程序停下来等用户输入，括号里的提示语会显示在屏幕上，用户敲完回车，输入的内容就交还给了程序。

一个关键规则：input() 返回的永远是字符串——哪怕用户输入 18，程序拿到的也是 "18"。所以要参与数学运算，必须先用上一章的 int() 或 float() 转换：

age = int(input("你几岁？"))
print("明年你就 " + str(age + 1) + " 岁了")

常见问题：忘记转换就直接 age + 1，会报 TypeError，说字符串不能和整数相加——这个错我们在第五章见过，现在你知道它为什么总发生了。

print 的两个小开关

print("a", "b", "c")          # a b c —— 逗号分隔，默认用空格隔开
print("a", "b", sep="-")      # a-b —— sep 指定分隔符
print("加载中", end="")        # end 默认是换行，改成空串就不换行
print("完成")                  # 输出：加载中完成

f-string：现代的输出方式

用 + 和 str() 拼句子既啰嗦又容易漏空格。f-string 是目前最推荐的写法——在字符串前加 f，用 {} 直接嵌入变量：

name = "小明"
age = 18
print(f"我叫 {name}，今年 {age} 岁")

{} 里可以放任何表达式：

print(f"明年 {age + 1} 岁")        # 明年 19 岁
print(f"1 加 2 等于 {1 + 2}")      # 1 加 2 等于 3

还能控制小数位数——:.2f 表示保留两位小数：

pi = 3.14159
print(f"圆周率约为 {pi:.2f}")      # 圆周率约为 3.14

回忆第六章：处理浮点误差时我们用过 round(0.1 + 0.2, 2)；{x:.2f} 是在显示层面控制位数，更常用。

动手：BMI 计算器

综合运用本章和前几章的知识，做一个真正能用的小工具：

height = float(input("请输入身高（米）："))
weight = float(input("请输入体重（千克）："))

bmi = weight / height ** 2

print(f"你的 BMI 是 {bmi:.2f}")

if bmi >= 24:
    print("偏重，注意饮食和运动")
elif bmi >= 18.5:
    print("正常，保持住")
else:
    print("偏轻，多吃点")

短短一段代码：运算优先级（height ** 2）、类型转换、f-string、条件语句全部上阵。输入身高 1.75、体重 65，看看结果是否约为 21.22。

简易收银台。让 BMI 计算器再进一步：这次要模拟真实收银，没有参考答案。

功能要求：

  1. 依次输入单价和数量（都可能带小数），算出总价；
  2. 优惠规则：总价满 100 元打九折，否则原价；

列表与元组

一个变量装下所有成绩

要存全班 50 个学生的成绩，起 50 个变量名？当然不。列表（List）是 Python 最常用的容器——用方括号把一组数据装进一个变量：

scores = [90, 85, 77, 100, 66]
print(scores)        # [90, 85, 77, 100, 66]

列表里的元素可以是任何类型，甚至混合存放，但同一类数据放一起更常见。

用索引访问：从 0 开始数

scores = [90, 85, 77, 100, 66]

print(scores[0])     # 90 —— 第一个元素
print(scores[3])     # 100
print(scores[-1])    # 66 —— 负数表示倒数

索引从 0 开始是编程世界的通用约定，也是新手第一大坑：“第 1 个”是 [0]，“第 5 个”是 [4]。

索引越界会报错——只有 5 个元素，访问 scores[5] 就得到 IndexError。

遍历：配合 for 逐个处理

第八章说过 for 的本质是遍历序列，列表就是最典型的序列：

for s in scores:
    print(s)

需要序号时，最地道的工具是 enumerate()——它每轮交出一个 (序号, 元素)，用两个变量接住（这种写法叫解包，本章元组一节会讲）：

for i, s in enumerate(scores):
    print(f"第 {i + 1} 个成绩是 {s}")

两个列表一一对应地并行遍历，用 zip()：

names = ["小明", "小红"]
scores2 = [90, 85]

for name, score in zip(names, scores2):
    print(f"{name}：{score} 分")

增、删、改

scores = [90, 85, 77]

scores.append(100)      # 末尾添加 → [90, 85, 77, 100]
scores.insert(0, 60)    # 插到索引 0 的位置 → [60, 90, 85, 77, 100]
scores[1] = 86          # 修改 → [60, 86, 85, 77, 100]
scores.remove(77)       # 按值删除 → [60, 86, 85, 100]
last = scores.pop()     # 取出并返回最后一个元素 → scores 变 [60, 86, 85]，last 是 100

三个“加”各管一处：append() 加在末尾、insert() 加在指定位置、extend() 把另一个列表整个接上。

两个“删”要分清：remove() 按值删，而且只删第一个匹配项（列表里有两个 77，也只删掉前面那个）；pop() 按位置删，并把删掉的值交给你——要“用完就删”时非常顺手。

列表也支持 + 和 *（规则和字符串一样）：

a = [1, 2, 3]
b = [4, 5]

print(a + b)      # [1, 2, 3, 4, 5] —— 拼接
a.extend(b)       # 把 b 的元素逐个塞进 a，效果类似 a = a + b；但 extend 是原地修改，不产生新列表

细节：scores.append(100) 这种用“点”调用的写法叫方法（Method）——挂在数据身上的函数。第十三章正式学函数，第十七章你会发现方法正是面向对象的冰山一角。

切片：取一段

scores = [90, 85, 77, 100, 66]

print(scores[1:3])    # [85, 77] —— 索引 1 到 2，不含 3
print(scores[:2])     # [90, 85] —— 从头开始取
print(scores[2:])     # [77, 100, 66] —— 一直取到结尾

规则和 range 一致：含头不含尾。切片还有第三个参数步长：scores[::2] 每两个取一个，得到 [90, 77, 66]；步长为 -1 时，scores[::-1] 就是整个列表倒过来。

重要细节：赋值不是复制。b = scores 并不会复制列表，只是给同一个列表多贴了一个标签——通过 b 做的修改，scores 看得一清二楚。想要一个副本，用切片：b = scores[:]。这是新手最容易踩的隐性坑，本章挑战作业会用到它。
但要留个心眼：切片复制的是最外面那一层。如果列表里装的还是列表或字典（下一章会学），b = a[:] 之后改 b[0] 里面的东西，a[0] 照样跟着变——因为两个列表的第 0 项指向的还是同一个内层容器。一层数据（数字、字符串）用切片就够；嵌套数据要复制得更彻底，等用到时再说。

常用统计与成员判断

scores = [90, 85, 77, 100, 66]

print(len(scores))    # 5    个数
print(sum(scores))    # 418  总和
print(max(scores))    # 100  最大
print(min(scores))    # 66   最小
print(sum(scores) / len(scores))    # 83.6 平均分

in 可以判断元素是否存在，结果是布尔值——第五章学的 bool 又立新功：

print(100 in scores)    # True
print(59 in scores)     # False

排序：sort 与 sorted

scores = [90, 85, 77, 100, 66]

scores.sort()                  # 原地排序，直接改自己 → [66, 77, 85, 90, 100]
scores.sort(reverse=True)      # 倒序 → [100, 90, 85, 77, 66]

new_list = sorted(scores)      # 不动原列表，返回一个排好的新列表

记住这对搭档的区别：sort() 改自己，sorted() 给新列表——想保留原始顺序时用后者。另有一个 reverse() 方法，不做比较排序，只把现有顺序整个颠倒。

选学：按“规则”排序

sort() 和 sorted() 默认按大小排。想按自己的规则排时，用 key= 告诉它“拿什么去比较”：

words = ["banana", "kiwi", "apple"]
print(sorted(words, key=len))     # ['kiwi', 'apple', 'banana'] —— 按长度排

nums = [-5, 3, -1, 4]
print(sorted(nums, key=abs))      # [-1, 3, 4, -5] —— 按绝对值排

pairs = [(2, "b"), (1, "c"), (3, "a")]
print(sorted(pairs, key=lambda p: p[1]))   # [(3, 'a'), (2, 'b'), (1, 'c')] —— 按第二个元素排

lambda p: p[1] 是“临时用一次的小函数”，等价于一个只做 return p[1] 的函数。现在只要看得懂，用到时会照抄 key=lambda ... 这个形状就够了。

元组：不可修改的列表

元组（Tuple）用圆括号，用法和列表几乎一样，唯一区别：创建后不能增、删、改：

point = (3, 5)

print(point[0])       # 3 —— 访问没问题
point[0] = 10         # ❌ TypeError！元组不可修改

什么时候用元组？数据不该被改动的时候——坐标、一年的十二个月、固定的配置项。

再学一个实用语法——解包：一次把元组里的值分别赋给多个变量：

x, y = (3, 5)
print(x, y)           # 3 5

本章挑战作业

体操评分。真实比赛里，选手的得分要去掉一个最高分、去掉一个最低分后取平均，没有参考答案：

scores = [9.2, 8.8, 9.5, 8.9, 9.1, 8.7]    # 六位裁判的打分，互不相同

请算出最终得分并输出，保留两位小数。

要求：

  1. 最高分和最低分必须用 max() / min() 找出来，不许用眼睛看后写死 9.5 和 8.7；
  2. 原列表 scores 在程序结束后必须保持原样——直接在它上面 remove 会把它改掉，想想本章有没有办法先得到一个副本再删；
  3. sum / len 求平均，f-string 格式化输出。

提示：本章的切片可以复制列表——scores[:] 就是“从头到尾整段取”出来的副本。在副本上 remove(max(...)) 和 remove(min(...))，再对副本求平均。如果结果出现 9.000000000000002 这种尾巴——回忆第六章的浮点误差，用 :.2f 解决。

自测标准：去掉 9.5 和 8.7 后，剩余四个数之和为 36.0，最终输出 9.00。

本章小结

  • 列表用 [] 装一组数据，索引从 0 开始，负索引从后往前数。
  • for 遍历列表；要序号用 enumerate()，两个列表并行遍历用 zip()。
  • append 添加、insert 插到指定位置、remove 按值删（只删第一个）、pop 按位置删、赋值修改、+ / extend 拼接；“点”出来的用法叫方法。
  • 切片含头不含尾，步长可控制方向；b = a 只是别名，真副本要用 a[:]。
  • 排序：sort() 改自己，sorted() 返回新列表；len / sum / max / min / in 是高频工具。
  • 元组是不可修改的列表，适合固定不变的数据；解包可以一次赋多个变量。

字典与集合

按名字找，而不是按位置找

在电话簿里找“张三”，你不会从第一页一页数过去——直接翻到“张”开头的那页。字典（Dictionary）就是这样的容器：每个数据都挂着一个“名字”（键，key），通过键直接取值，而不是像列表那样靠位置。

字典的基本操作

student = {"name": "小明", "age": 18}

print(student["name"])        # 小明 —— 按键取值
student["score"] = 95         # 键不存在 → 新增键值对
student["age"] = 19           # 键已存在 → 修改值
del student["score"]          # 删除这个键值对
print(len(student))           # 2 —— 键值对的个数

注意：花括号 {} 定义的是字典（键值对），方括号 [] 定义的是列表——但访问元素时两者都用方括号：student["name"]。

字典的键通常是字符串，值可以是任何类型，同一个字典里各值的类型也可以不同。

安全访问：.get()

访问不存在的键会报错：

print(student["phone"])       # ❌ KeyError

用 .get() 可以安全访问——键不存在时不报错，返回 None（表示“什么都没有”）：

print(student.get("phone"))             # None
print(student.get("phone", "未填写"))    # 未填写 —— 第二个参数是默认值

判断“是不是 None”要用 is：student.get("phone") is None。

is 和 == 到底差在哪：== 问的是“两个值相等吗”，is 问的是“是不是同一个东西”。判断“有没有值”用 is None，判断“两个值一不一样”用 ==。完整的区别涉及内存，以后再展开；现在记住这个固定搭配就够：判断 None 用 is。

in 用在字典上判断的是键是否存在："age" in student 是 True，"phone" in student 是 False。

遍历字典

for key, value in student.items():
    print(key + "：" + str(value))

items() 把每个键值对拆成 (键, 值)，配合上一章的解包语法，一个循环同时拿到两个东西。只需要键或只需要值时，还有 keys() 和 values()：

for name in student.keys():      # 只拿键
    print(name)

for value in student.values():   # 只拿值
    print(value)

实战：用字典计数

统计每个字符出现的次数——字典最经典的应用：

text = "hello"

counts = {}
for ch in text:
    counts[ch] = counts.get(ch, 0) + 1

print(counts)        # {'h': 1, 'e': 1, 'l': 2, 'o': 1}

逐行读：字符串可以被 for 遍历（下一章细讲）；字符第一次出现时 get 返回默认值 0，加 1 后存入；再次出现时，在上次的基础上加 1。

集合：去重和判断利器

集合（Set）的特点：元素不重复、无顺序：

nums = [1, 2, 2, 3, 3, 3]

unique = set(nums)         # 列表转集合，重复的自动消失
print(unique)              # {1, 2, 3}

print(2 in unique)         # True —— 成员判断非常快
unique.add(4)              # 添加元素

最常见的两个用途：给列表去重（list(set(nums)) 转回列表）和快速判断某个元素存在与否。

必踩的坑：空的花括号 {} 是空字典，不是空集合！想创建一个空集合，必须写 set()。

a = {}          # 这是空字典
b = set()       # 这才是空集合
c = {1, 2, 3}   # 有元素时，花括号才是集合

判断一个变量到底是哪种类型，用第五章的 type() 一试便知。

嵌套容器：列表装字典

真实世界的数据几乎都长这样——一个列表，每个元素是一个字典：

students = [
    {"name": "小明", "score": 90},
    {"name": "小红", "score": 85},
    {"name": "小刚", "score": 77},
]

for stu in students:
    print(f"{stu['name']} 考了 {stu['score']} 分")

读法：students 是列表，students[0] 取出第一个字典，students[0]["name"] 再取出里面的值。这种“两层容器”能表达一张表格，以后接触文件和接口数据时，见到的多半还是这个形状。

四大容器对比

容器符号特点典型用途
列表 list[ ]有序、可修改一串会变化的数据
元组 tuple( )有序、不可修改固定不变的一组值
字典 dict{键: 值}键值对、按键存取按名字管理数据
集合 set{1, 2, 3}不重复、无序去重、成员判断（空集合要写 set()）

选学：列表推导式

有一类循环特别常见——“把每个元素变换一下，收集成新列表”：

scores = [90, 85, 77, 100, 66]

bonus = []
for s in scores:
    bonus.append(s + 5)

print(bonus)    # [95, 90, 82, 105, 71]

Python 为这个固定模式提供了紧凑写法——列表推导式：

bonus = [s + 5 for s in scores]
print(bonus)    # [95, 90, 82, 105, 71]

还能带上 if 做筛选：

passed = [s for s in scores if s >= 60]
print(passed)    # [90, 85, 77, 100]

读法：“对 scores 里的每个 s，若满足 s >= 60，就把 s 收进新列表”。本篇只要求能看懂别人的推导式；自己写时拿不准，就老老实实写 for 循环——两者完全等价，清晰永远优先。

同样的形状对字典和集合也成立，各看一个例子就够：

# 字典推导式：把分数映射成等级
raw = [90, 55, 77]
levels = {s: ("及格" if s >= 60 else "不及格") for s in raw}
print(levels)    # {90: '及格', 55: '不及格', 77: '及格'}

# 集合推导式：收集所有出现过的首字母（集合自动去重，用 sorted 让输出顺序固定）
words = ["apple", "banana", "avocado"]
print(sorted({w[0] for w in words}))    # ['a', 'b']

模拟登录系统。真实软件的登录逻辑，你现在就有能力实现，没有参考答案：

users = {"admin": "123456", "xiaoming": "abc888"}    # 用户名 → 密码

功能要求：

  1. 循环提示输入用户名和密码，最多允许尝试 3 次；
  2. 用户名密码都对：打印欢迎语，程序正常结束；
  3. 三次都失败：打印“账号已锁定”，程序结束；
  4. 每次失败后，提示还剩几次机会。

要求：

  • 用 while + 计数器实现“最多三次”（回忆第八章的三要素）；
  • 查用户必须用 .get() 或 in，不许直接 users[name]——想想为什么（想想不存在的用户名）；
  • 用户不存在和密码错误，可以只提示“用户名或密码错误”一种信息（真实网站也这么干，这是安全考虑）。

提示：主循环是 while True 还是“条件式 while”？两种都能写对，试着想清楚各自的退出条件。计数器每次失败 += 1，等于 3 就锁定——把第七章的条件、第八章的循环、本章的字典串起来。

自测标准：连续输错 3 次触发锁定；第 2 次输对能正常进入且剩余次数提示正确（第一次失败后应提示“还剩 2 次机会”）。

  • 访问可能不存在的键用 .get()，避免 KeyError；判断 None 用 is。
  • items() 遍历键值对，keys() / values() 只拿键或值；字典 + get 计数是经典套路。
  • 集合天生去重，in 成员判断快；list(set(...)) 是去重惯用法。
  • 列表装字典的嵌套容器，能表达“表格”型数据。
  • 推导式（列表 / 字典 / 集合）是“变换 + 收集”循环的紧凑写法，本篇要求看懂即可。
  • 四大容器各有分工，选谁取决于数据的特点。

字符串进阶

字符串也是序列

第十章说 for 可以遍历序列——列表可以，字符串同样可以，它就是一串字符组成的序列。列表学过的操作，字符串几乎全适用：

s = "Python"

print(s[0])       # P
print(s[-1])      # n —— 负索引照样有效
print(s[1:4])     # yth —— 切片含头不含尾
print(len(s))     # 6

for ch in s:
    print(ch)

字符串不可修改

s = "Python"
s[0] = "J"       # ❌ TypeError：字符串不支持修改

想“改”字符串，只能创建一个新字符串：

s = "J" + s[1:]
print(s)         # Jython

常用方法：字符串的内置技能

第十章见过 scores.append() 这种“点”出来的方法，字符串自带一大批高频方法：

s = "  Hello, Python  "

print(s.strip())                   # 去掉两端空格 → "Hello, Python"
print(s.strip().lower())           # 全变小写 → "hello, python"（方法可以链着用）
print(s.replace("Hello", "Hi"))    # 替换 → "  Hi, Python  "
print("python".upper())            # PYTHON —— 全大写

split() 按分隔符把字符串拆成列表（又回到第十章）：

csv = "apple,banana,orange"
fruits = csv.split(",")
print(fruits)         # ['apple', 'banana', 'orange']

in 也能用在字符串上，判断子串是否存在：

print("Py" in "Python")    # True

再记三个高频方法：

print("123".isdigit())             # True —— 全是数字字符才返回 True
print("hello world".find("wor"))   # 6 —— 子串首次出现的位置（找不到返回 -1）

parts = ["apple", "banana", "orange"]
print("-".join(parts))             # apple-banana-orange

join() 是 split() 的逆操作——用指定分隔符把一个字符串列表粘成一个字符串。

关键细节：这些方法都不会改变原字符串（它不可修改），而是返回一个新字符串。所以执行 s.strip() 之后 s 仍是原样，要写 s = s.strip() 才真正更新变量。

转义字符：\n 和它的朋友们

有些字符没法直接写进字符串，比如“换行”。用反斜杠 \ 转义：

print("第一行\n第二行")       # \n 换行
print("姓名\t成绩")           # \t 制表符，用于对齐
print("他说：\"你好\"")        # \" 在双引号字符串里再放双引号

回忆第四章“只用英文字符”——转义字符同样必须用英文半角 \，写成中文的 \ 会直接报错。

还有两个相关的实用写法：

text = """三引号字符串
可以原样保留
很多行的内容"""                    # 多行文本，不用自己拼 \n

path = r"C:\new\folder"           # 字符串前加个 r：原始字符串
print(path)                       # C:\new\folder —— \ 原样保留

r"..." 叫原始字符串（raw string），反斜杠失去转义能力、按字面输出。最典型的场景是 Windows 文件路径："C:\new\test" 里的 \n 会被当成换行符，写成 r"C:\new\test" 就安全了——第十六章读写文件时会用到。

动手：整理用户输入

用户的输入常常不规范——带空格、大小写混乱。处理输入的第一课：

answer = input("你同意吗？(yes/no)：")

answer = answer.strip().lower()

if answer == "yes":
    print("好的，继续")
else:
    print("已取消")

无论用户输入 " YES "、"Yes" 还是 "yes"，都能正确识别。处理用户输入前先 strip() + lower()，是很实用的好习惯。

选学：一次读入多个值

split() 和 input() 放在一起，能一次读进好几个值——写脚本和刷题时天天用：

# 假如用户输入：3 5
a, b = input("请输入两个数，用空格隔开：").split()
print(a, b)          # 3 5 —— 注意，它们现在还是【字符串】

a, b = int(a), int(b)
print(a + b)         # 8

读法：input() 拿到整行 "3 5"，.split()（不填参数时按空白拆）把它拆成 ["3", "5"]，再用上一章学的解包分给 a 和 b。

两个要点：拆出来的一律是字符串，要算数得自己转；如果输入的个数和左边变量数对不上，会报 ValueError。所以真正写工具时，更稳妥的写法是先 parts = input().split()，判断完长度再取用。

密码合规检查器。注册账号时网站会实时检查密码强度——现在你知道怎么实现了，没有参考答案：

password = "ab 123"      # 可以随意替换成别的密码来测试

检查三条规则，并输出每一条是否通过，最后给出总体结论（全部通过才算合格）：

  1. 长度至少 8 个字符；
  2. 不含空格；
  3. 至少包含一个数字。

要求：

  • 每条规则的检查结果都要单独 print 出 True/False 或“通过/不通过”；
  • “至少包含一个数字”是最难的一条——不许写 10 个 in 挨个判断，要用循环遍历字符串的每个字符；
  • 用三个密码测试："ab 123"（规则 1、2 不过）、"abcdefgh"（规则 3 不过）、"ab12cd34"（全部通过）。

提示：规则 3 需要“发现过至少一个数字”这个信息——在循环前准备一个 found = False（布尔变量是第五章的），循环中逐个检查字符：ch.isdigit() 或 ch in "0123456789" 都能判断是不是数字字符，是就把 found 改成 True。循环结束后，found 就是答案。

自测标准：三个测试密码的三条规则判定全部正确。这道题的新收获是“累加器/标志变量”模式——循环中收集信息、循环后使用，它是后面无数算法题的地基。

本章小结

  • 字符串是字符的序列：索引、切片、遍历、len() 全部适用。
  • 字符串不可修改，“改”它实际是创建新字符串。
  • 高频方法：strip()、lower()/upper()、replace()、split() 与 join()、isdigit()、find()；方法返回新字符串，可以链式调用。
  • \n、\t、\" 是常用转义字符，必须用英文半角；"""...""" 写多行文本，r"..." 让反斜杠不转义（Windows 路径必备）。
  • 用户输入先 strip() + lower() 再处理。

函数

把代码打包复用

同一段逻辑要在三个地方用，复制粘贴三遍——需求一改就要改三处，还容易漏。函数（Function）就是解决方案：把一段代码打包起来、起个名字、随取随用。

其实我们一直在用函数：print()、input()、len()、int() 都是别人写好的函数。这一章，轮到自己写了。

定义与调用

def greet():
    print("你好！")
    print("欢迎学习 Python")

greet()     # 调用一次，执行一次
greet()

def 是 define（定义）的缩写。注意两点：

  • 函数体同样靠缩进归属——第四章的规则二在这里继续生效；
  • 定义不会执行，调用才执行。定义只是“登记”了这个函数，greet() 才是真正让它跑起来。

顺带认识一个占位语句 pass——它什么都不做，专门用来撑住语法结构：

def todo():
    pass          # 还没想好怎么写，先占个位，保证代码能运行

参数：给函数传数据

def greet(name):
    print("你好，" + name + "！")

greet("小明")     # 你好，小明！
greet("小红")     # 你好，小红！

name 是形参（形式参数，函数内部的占位符），调用时传入的 "小明" 是实参（实际参数）。

参数可以有多个，还可以带默认值——不传就用默认，传了就覆盖：

def greet(name, greeting="你好"):
    print(greeting + "，" + name + "！")

greet("小明")               # 你好，小明！
greet("小明", "早上好")      # 早上好，小明！

调用时还可以“指名道姓”地传参——关键字参数：

greet(greeting="早上好", name="小明")    # 早上好，小明！—— 顺序随意

参数一多时，关键字参数能明显减少传错顺序的概率。

一个必须提前知道的坑：默认值别用可变对象

默认值只在定义函数时算一次，之后每次调用用的都是同一个。如果默认值是列表，就会看到很诡异的现象：

def add_item(item, box=[]):      # ❌ 默认值是个列表
    box.append(item)
    return box

print(add_item("a"))    # ['a']
print(add_item("b"))    # ['a', 'b'] —— 上一次的结果还在！

原因：box=[] 只创建了一次，两次调用共用同一个列表。正确写法是把默认值设成 None，进了函数再建：

def add_item(item, box=None):
    if box is None:
        box = []
    box.append(item)
    return box

print(add_item("a"))    # ['a']
print(add_item("b"))    # ['b'] —— 互不影响

一句话结论：默认值用数字、字符串、True / False、None 这类不会变的东西；要用列表或字典，就照上面的写法绕一下。

返回值：把结果交回去

函数可以把计算结果返回给调用处：

def add(a, b):
    return a + b

result = add(3, 5)     # 函数算出 8，“交回”给调用处，存进 result
print(result)          # 8

return 和 print 是两回事——这是新手最容易混淆的地方：

  • print() 只是把结果显示在屏幕上，程序内部并没有拿到这个值；
  • return 才是把结果真正交回调用处，可以存进变量、继续参与运算。
def bad_add(a, b):
    print(a + b)        # 只打印，没有返回

x = bad_add(3, 5)       # 屏幕上显示 8，但 x 是 None！
print(x)                # None

没有 return 的函数，返回值是 None——第十一章 get() 里见过的那个“什么都没有”。

return 还能一次返回多个值——其实是打包成元组，配合第十章的解包接收：

def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([3, 1, 4, 1, 5])
print(low, high)        # 1 5

变量的作用范围

函数内部定义的变量，外面看不到：

def test():
    inner = 42

test()
print(inner)          # ❌ NameError：外部不存在 inner

只在函数内部有效的变量叫局部变量。反过来，函数可以读取外面定义的变量。初学阶段记住一句话即可：函数自己的事自己了，别依赖外部的临时变量。

动手：写一个判断偶数的函数

把第七章的奇偶判断打包成函数：

def is_even(n):
    return n % 2 == 0

print(is_even(4))     # True
print(is_even(7))     # False

注意函数名的 is 前缀——返回布尔值的函数常用这种命名，调用起来像在读一句话：“4 是偶数吗？True”。

本章挑战作业

质数猎手。质数是只能被 1 和它本身整除的数（2、3、5、7、11……）。这一题是函数 + 循环 + 条件的综合体，没有参考答案：

任务一：写一个函数 is_prime(n)，返回 True 或 False，表示 n 是不是质数。

任务二：用这个函数，打印 2 到 50 之间所有的质数。

要求：

  1. is_prime 内部用循环：让 n 除以 2 到 n-1 之间的每个数，只要有一个能整除就立刻 return False——回忆本章“return 可以提前结束函数”；
  2. 循环全部跑完都没找到因数，才 return True；
  3. 特殊值要单独处理：n 小于 2 时直接返回 False（1 和 0 都不是质数）；
  4. 任务二用 for + range 配合你的函数完成，输出一行一个质数。

提示：任务二就是在“遍历候选者，挑出合格的”——和遍历列表挑出及格成绩是同一个套路，只不过“合格”的判断被你封装进了函数里。如果想验证对错：2 到 50 之间共有 15 个质数，最后一个是 47。

自测标准：is_prime(2) 为 True、is_prime(9) 为 False、is_prime(1) 为 False；任务二恰好输出 15 行。

本章小结

  • def 定义函数，调用才执行；函数体靠缩进归属，没想好时用 pass 占位。
  • 形参是占位符，实参是调用时传入的值；参数可带默认值，也可用“参数名=值”指名传参。
  • return 把结果交回调用处，可以一次返回多个值；print 只是显示——没有 return 的函数返回 None。
  • 函数内定义的是局部变量，外部访问不到。
  • 返回布尔值的函数常用 is_ 前缀命名。

模块与标准库

不必重复造轮子

有些代码几乎每个程序员都要用——算平方根、生成随机数、处理时间。Python 把这些常用工具打包成模块（Module），一行 import 就能拿来就用。

标准库是随 Python 一起安装的模块集合——回忆第二章：安装 Python 时装的除了解释器，还有“标准库和配套工具”，说的就是它。标准库不需要额外安装，import 即可使用。

import 的两种常用姿势

import math

print(math.sqrt(16))    # 4.0 —— 平方根
print(math.pi)          # 3.141592653589793 —— 圆周率

用“模块名.工具名”的方式访问。如果某个工具用得频繁，可以单独导入，省掉前缀：

from math import sqrt

print(sqrt(16))         # 4.0 —— 不用再写 math.

还有第三种 import math as m（起别名），遇到名字很长的模块才用，初学少见。

实用模块巡礼

random —— 随机数，猜数字、抽卡这类程序全靠它：

import random

print(random.randint(1, 100))                  # 1~100 的随机整数（含两端）
print(random.choice(["石头", "剪刀", "布"]))     # 随机选一个

time —— 时间：

import time

print(time.time())     # 当前时间戳（从 1970 年到现在的秒数）
time.sleep(1)          # 程序暂停 1 秒

标准库有几百个模块：处理日期的 datetime、读写 csv 表格的 csv、压缩文件的 zipfile……不需要背，用到时查官方文档即可。

提醒：给自己的文件起名时，别用 random.py 这类和标准库撞名的名字——否则 import random 会导入你自己的文件而不是标准库，报出莫名其妙的错误。

第三方库：生态的力量

标准库之外，全世界的开发者还贡献了海量第三方库——第一章提到过的 NumPy、Pandas、PyTorch 都是。它们需要先安装：

pip install requests

pip 是随 Python 一起安装的安装工具（也是第二章说过的“配套工具”之一）。总结两者的区别：标准库装好 Python 就有，第三方库要先用 pip 安装。

pip 本身只有几条命令，值得现在就记住：

命令作用
pip install 包名安装
pip list看看已经装了哪些包
pip install --upgrade 包名升级到最新版
pip uninstall 包名卸载

下载太慢？ 加上国内镜像源即可：pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple，速度通常快很多。

选学：虚拟环境 venv

装第三方库之前，有件事最好先知道。假设 A 项目要用 requests 的旧版本，B 项目要用新版本——都装进同一个 Python 里，必然打架。

虚拟环境（venv）的思路是：给每个项目配一个独立的“小 Python”，各装各的，互不干扰。用法只有三步：

python -m venv .venv                  # 1. 在项目文件夹里创建虚拟环境
.venv\Scripts\activate                # 2. 激活（Windows）
# source .venv/bin/activate           #    激活（macOS / Linux）
pip install requests                  # 3. 之后的 pip 都会装进这个环境里

激活成功后，命令行的提示符前面会出现 (.venv) 字样——这就是“当前处在该环境中”的标志。退出用 deactivate。

初学阶段不做这一步也能跑通本教程，但只要你开始正式做一个项目，就该用它。VS Code 会自动识别项目里的 .venv，并在你新建终端时替你激活。

动手：掷骰子模拟器

import random

while True:
    dice = random.randint(1, 6)
    print(f"掷出了 {dice} 点")
    again = input("再来一次？(y/n)：")

while + break（第八章）、input（第九章）、random（本章）——八行代码串起三章知识。

选学：写自己的模块

前面用的都是别人的模块。其实你自己写的 .py 文件本身就是一个模块——把函数放进去，另一个文件就能 import 它。

新建 mytool.py：

def greet(name):
    return "你好，" + name + "！"

再新建 main.py，跟它放在同一个文件夹里：

import mytool                        # 文件名去掉 .py，就是模块名

print(mytool.greet("小明"))           # 你好，小明！

from mytool import greet             # 也可以只导入其中一样
print(greet("小红"))                  # 你好，小红！

这才是“模块”这个词真正的含义：一个 .py 文件，就是一个能被别人拿来用的模块。标准库里的 math、random，无非是别人写好的、随 Python 一起装好的 .py 文件而已。

注意：import 只在同一个文件夹和 Python 的安装目录里找模块。项目大起来以后，代码会按文件夹分层组织，那就是“包（package）”的话题了，进阶篇再讲。

选学：if __name__ == "__main__":

上一节说过，import mytool 会把 mytool.py 从头到尾执行一遍。如果那个文件里除了函数定义，还写了些“自己测试用”的代码，别人一 import 就会顺带跑起来——这通常不是你想要的。

__name__ 就是用来区分这两种情况的。它是每个文件里都自动存在的变量：直接运行这个文件时，它的值是 "__main__"；被别人 import 时，它的值是模块名（文件名去掉 .py）。所以下面这个套路的意思是“只在直接运行本文件时才执行这一段”：

print(__name__)          # 直接运行本文件时，输出 __main__

if __name__ == "__main__":
    print("我是被直接运行的，不是被 import 的")

有了它，就能把“给别人用的函数”和“给自己测试的代码”放进同一个文件：别人 import 你的模块时，只会拿到函数，不会顺带执行你的测试代码。

异常处理

意外总会发生

这本教程一直在教你看报错：TypeError、IndentationError、KeyError……报错的正式名字叫异常（Exception）。默认情况下，异常一旦发生，程序立刻终止。

但用户是不可控的：你让他输数字，他偏输 "abc"。好的程序要能接住意外，给用户一条退路，而不是自己崩溃——这就是异常处理。

try / except：尝试与兜底

try:
    age = int(input("请输入年龄："))      # 这行可能报错
    print(f"明年你就 {age + 1} 岁")
except ValueError:
    print("输入的不是数字，请重试！")       # 报错时执行这里

print("程序继续运行")                      # 两种情况都会走到这里

结构规则：

  • try 里放“可能出错的代码”，except 里放“出错后的对策”；
  • try 块中一旦发生异常，剩下的代码不再执行，直接跳到对应的 except；
  • 没有异常发生，except 就被跳过；
  • 无论哪种情况，程序都不会崩溃，继续往下运行。

except 后面写的是异常类型，只接住指定的类型。ValueError 是“值不合适”——"abc" 转不成 int 就是它。

一个 try 可以接多种异常

try:
    a = int(input("被除数："))
    b = int(input("除数："))
    print(f"结果为 {a / b}")
except ValueError:
    print("请输入数字")
except ZeroDivisionError:
    print("除数不能为 0")

输入 10 和 0，会得到“除数不能为 0”，程序稳如泰山。

还有 finally 和 assert

finally：不管有没有出错都会执行的收尾代码。它最常见的搭档是文件——无论中途成功还是失败，都要有个收尾动作：

try:
    f = open("不存在的文件.txt", "r", encoding="utf-8")   # 这里一定失败
    print(f.read())
except FileNotFoundError:
    print("文件不存在")
finally:
    print("无论成功还是失败，这句都会执行")

提示：下一章会学到 with open(...)，它把“自动关闭文件”做成了语法，所以实际写文件时 finally 用得比这里少——但“无论如何都要收尾”这个想法很重要。

assert（断言）：给“我认为这里一定是这样”加一道自动检查，条件不成立就直接报 AssertionError：

age = 18
assert age >= 18, "年龄必须满 18"    # 不成立就报错，并带上这句说明
print("断言通过")

它适合写在调试和自测里（比如验证自己的函数返回值对不对），不适合用来处理用户输入错误——用户乱输要用 try / except，那才是本章前面讲的正事。

选学：主动抛出异常（raise）

前面都是“异常发生了，我去接住”。反过来，你也可以主动抛出异常：当调用者给的参数根本不合理时，与其让它悄悄算出个错结果，不如当场喊停。

def set_age(age):
    if age < 0 or age > 150:
        raise ValueError("年龄必须在 0 到 150 之间，收到的是 " + str(age))
    return age

print(set_age(18))       # 18

try:
    set_age(-5)
except ValueError as e:
    print("ValueError:", e)

raise 后面跟一个异常对象。好处是：错误在发生的地方就被明确指出，而不是拖到很远的地方，才暴露成一个看不懂的结果。

三者的分工可以这样记：

手段用在哪出问题说明什么
assert调试、自测你自己的代码写错了
raise正式逻辑调用你的人用错了
try / except正式逻辑外部世界（用户输入、文件）不可控

想在项目里定义自己的异常类型，只要继承 Exception 就行（继承的概念第十七章会讲）：class MyError(Exception): pass。进阶篇再展开。

异常触发场景首次出现在

try:
    height = float(input("请输入身高（米）："))

选学：从“读报错”到“调试”

到这里你已经会读报错了。但如果程序不报错、只是结果不对呢？这时需要调试（Debug）——主动去观察程序运行中每一步的真实情况。

第一步：缩小范围。 在可疑的位置插一句 print()，把中间变量的值打出来，看它是不是你以为的那个值。这是最朴素也最有效的手段，写十年代码也还在用：

total = 0
for s in scores:
    total += s
    print(f"加上 {s} 后，total = {total}")     # 每一步都摊开看

第二步：用断点。 在 VS Code 里，直接点行号左边的空白处，会出现一个红点——这就是断点（Breakpoint）。按 F5 启动调试，程序会跑到这一行停下来，这时你可以：

  • 在左侧的“变量（VARIABLES）”面板里看到当前所有变量的值；
  • 按 F10（单步跳过）一行一行往下走，每走一步都看变量怎么变；
  • 按 F5（继续）直接跑到下一个断点。

调试的核心只有一句话：不要靠猜，去看真实的值。 程序的行为和你以为的不一样，永远是某个变量的值和你以为的不一样——断点就是让你亲眼看到它的工具。这一招配合本章的异常处理，程序再出问题你也不至于束手无策。

造一个“永不崩溃”的输入函数。真实软件里“请你输入一个数字”的对话，背后都有一个反复要求重试的机制。现在把它封装成函数，没有参考答案：

任务一：写函数 ask_int(prompt)：

  1. 显示 prompt 提示语，读取用户输入并尝试转成整数；
  2. 转换失败就提示“请输入一个整数”，然后再次要求输入——直到成功为止；
  3. 成功后把这个整数返回给调用处。

要求：

  • 任务二的除数为 0 属于另一种异常（回忆本章速查表），要在调用处单独接住；
  • 主程序里不许出现裸的 int(input(...))——所有整数输入都必须走你的 ask_int。

提示：while True + try/except + return 三件套：try 里转换成功就 return（回忆第十三章：return 会立刻结束函数，正好也跳出了循环）；转换失败会跳到 except，提示后循环自动进行下一轮。想通“return 能同时结束函数和循环”这一层，这道题就通了。

  • 遇到新异常，先读最后一行的类型和说明，再决定是改代码还是加处理。
  • 程序不报错但结果不对时，用 print 缩小范围，或用断点 + F10 单步观察真实的值。

文件读写

让数据留下来

程序里的变量都活在内存中——程序一关，全部蒸发。想让数据长期保存（用户记录、配置、统计结果），就要写到文件里。Python 读写文件，只需要一个 open() 函数。

写文件与读文件

# 写：模式 "w" 是 write
with open("diary.txt", "w", encoding="utf-8") as f:
    f.write("第一天：学了变量\n")
    f.write("第二天：学了循环\n")

# 读：模式 "r" 是 read
with open("diary.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

逐个拆解：

  • open("文件名", "模式") 打开文件，返回一个文件对象，这里起名叫 f；
  • with 语句会在代码块结束时自动关闭文件——这是标准写法，不用担心忘记关闭；
  • encoding="utf-8" 指定编码，要写中文务必加上，否则 Windows 上容易出现乱码；
  • \n 是换行符（第十二章的转义字符），一行写一条，方便以后逐行读。

打开模式速查：

模式含义注意
r读文件不存在会报 FileNotFoundError
w写（清空重写）会清空文件原有内容！
a追加在文件末尾续写，不清空

常见事故：想给文件“补充”几行，却用了 "w" 模式——旧内容被全部清空。往已有文件续写，用 "a" 模式。

逐行读取

文件很大时，f.read() 一次读完可能吃力，更常用逐行遍历——循环又来了：

with open("diary.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line, end="")     # line 自带换行符，end="" 避免双重换行

回忆第九章：print 的 end 参数默认是换行 \n，这里改成空字符串。

和异常处理配合

文件可能不存在——被用户删了，或者名字写错了。上一章学的 try / except 立刻派上用场：

try:
    with open("notes.txt", "r", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("文件不存在，先创建它吧")

动手：成绩存档

把成绩写进文件，再读出来统计——一条完整的“存储—读取—计算”链路：

scores = [90, 85, 77, 100, 66]

with open("scores.txt", "w", encoding="utf-8") as f:
    for s in scores:
        f.write(str(s) + "\n")          # 文件里只能放文本，先转字符串

with open("scores.txt", "r", encoding="utf-8") as f:
    total = 0
    count = 0
    for line in f:
        total += int(line.strip())      # 去掉换行符再转回整数
        count += 1

print(f"共 {count} 条成绩，总分 {total}，平均分 {total / count:.1f}")

输出：共 5 条成绩，总分 418，平均分 83.6。写入时 str() 转成文本（第十二章），读出时 strip() 去换行、int() 转回数字（第五、十二章）——写、读、算一气呵成。

选学：更省心的路径写法

本章一直用字符串表示文件名：open("diary.txt", ...)。文件一多、目录一深，靠字符串拼路径很容易出错。Python 自带了专门管路径的模块 pathlib：

from pathlib import Path

p = Path("data") / "diary.txt"     # 用 / 拼路径，比手写字符串清楚
print(p)                            # data\diary.txt（Windows；macOS/Linux 上是 data/diary.txt）

print(p.exists())                   # False —— 文件在不在，一句话就能问
print(p.name)                       # diary.txt —— 只要文件名
print(p.suffix)                     # .txt —— 只要扩展名

p.exists() 能在打开文件之前先问一句“你在不在”，很多场合比 try / except 更顺手。本章的记账本作业用 try / except 完全够用，等你开始处理多层目录时再回来用它。

简易记账本。做一个“每次运行都记得上一次”的支出记录程序——这是文件最典型的用途，没有参考答案：

功能要求：

面向对象编程入门

从“散装数据”到“对象”

描述一只狗，你需要几个变量：名字、年龄；再写几个函数：叫、吃。一只狗还好，一百只呢？变量满天飞，数据和操作互不关联。

面向对象编程（OOP）的思路：把“数据”和“操作这些数据的函数”打包成一个整体——对象（Object）。狗的名字、年龄和“叫”这个行为，都属于这只狗。

类（Class）是对象的“图纸”：先定义图纸，再按图纸造出一个个对象（也叫实例）。

定义一个类

class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(self.name + "：汪汪！")

my_dog = Dog("旺财", 3)      # 按图纸造一只狗
print(my_dog.name)           # 旺财
my_dog.bark()                # 旺财：汪汪！

这段代码信息量大，逐条解剖：

  • class Dog: 定义类，类名按惯例首字母大写（多个单词连写，如 MyDog，称为大驼峰）；
  • __init__ 是特殊方法：每次造新对象时自动执行，负责初始化。Dog("旺财", 3) 里的两个实参传给它；
  • self 指“当前这个对象自己”。执行 my_dog.bark() 时，self 就是 my_dog；
  • self.name = name 把传入的值挂在这个对象身上，成为它的属性；
  • bark 是方法——写在类里面的函数。第十章的 scores.append() 正是列表对象的方法，现在你知道它的由来了。

为什么要这么麻烦

用散装变量描述三只狗：name1、name2、name3……每只狗的数据和操作互不关联，改一处容易漏一片。用类，数据和操作绑定在一起，多少只都不乱：

dogs = [Dog("旺财", 3), Dog("小黑", 2), Dog("豆豆", 5)]

for dog in dogs:
    dog.bark()

输出：

旺财：汪汪！
小黑：汪汪！
豆豆：汪汪！

继承：站在类的肩膀上

类可以继承另一个类的全部能力，只需补充自己特有的部分：

class Puppy(Dog):          # 幼犬“是一种”狗 —— 继承 Dog
    def roll(self):
        print(self.name + " 打了个滚")

p = Puppy("团子", 1)
p.bark()        # 团子：汪汪！ —— 从 Dog 继承来的
p.roll()        # 团子 打了个滚 —— 自己新增的

“幼犬是一种狗”——继承表达的就是这种 is-a（是一种）关系。

说明：OOP 是个大话题，本章只求达到两个目标：看得懂别人写的类、自己会定义简单的类。封装、多态等深入内容，进阶时再学。

动手：写一个 Student 类

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def introduce(self):
        print(f"我叫 {self.name}，考了 {self.score} 分")

    def is_passed(self):
        return self.score >= 60

stu = Student("小明", 85)
stu.introduce()               # 我叫 小明，考了 85 分
print(stu.is_passed())        # True

is_passed 返回布尔值（第十三章的 is_ 前缀惯例），introduce 用了 f-string（第九章）——一个小小的类，浓缩了大半本教程。

本章挑战作业

银行账户类。把本章的知识组合成一个真正有用的类，没有参考答案：

写一个 BankAccount 类：

  1. 属性：owner（户主姓名）、balance（余额，新建账户时必须为 0）；
  2. 方法 deposit(amount)：存钱，余额增加；
  3. 方法 withdraw(amount)：取钱——余额够就扣减并输出新余额；余额不足时输出提示，并且余额一分不变；
  4. 方法 show()：输出“户主：xxx，余额：xxx 元”。

验证流程（写在你自己的代码里）：

acc = BankAccount("小明")
acc.deposit(100)
acc.withdraw(30)
acc.withdraw(500)     # 应该被拒绝
acc.show()            # 户主：小明，余额：70 元

要求：

  • 余额不足的判断用 if / else（第七章），条件是 amount > self.balance（比较运算符是第六章的）；
  • 新建账户时调用方只传姓名：BankAccount("小明")——想想 __init__ 的参数怎么设计；
  • 三次操作后余额必须恰好是 70，分毫不能差。

提示：对照 Dog 类的结构：__init__ 里两个属性，一个由实参传入、一个固定为 0。withdraw 里的“拒绝”不是 return False 那种复杂操作——打印一句提示、什么都不改，就是拒绝。

自测标准：四次调用后输出余额 70；把 withdraw(500) 换成 withdraw(70) 再跑一遍，余额应为 0，且继续取钱会被拒绝。

本章小结

  • 类是图纸，对象（实例）是按图纸造的产品；数据和函数打包在一起。
  • __init__ 负责初始化，self 指对象自己，属性挂在 self 上，方法写在类里。
  • 类名用大驼峰；. 用来访问对象的属性和方法。
  • 继承用 class 子类(父类) 表达“是一种”的关系，子类自动拥有父类的能力。
